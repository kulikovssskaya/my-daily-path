# Алгоритмы и структуры данных

> `#Algorithms` `#Python` `#ComputerScience`
>
> Базовые структуры данных и способ оценивать эффективность алгоритмов.

## Ключевые концепции

- **Асимптотический анализ (Big-O)** — оценка роста затрат при больших $n$.
- **Стек** — структура данных LIFO (последний пришёл — первый ушёл).
- **Очередь** — структура данных FIFO (первый пришёл — первый ушёл).
- **Deque** — двухсторонняя очередь.

## Подробное объяснение

### Асимптотический анализ

**Асимптотический анализ** оценивает эффективность алгоритма при очень больших
входных данных: как быстро растут затраты (время или память) в зависимости от
размера задачи $n$.

- $O(1)$ — время операции **не зависит** от количества элементов (например,
  «положить/снять» со стека занимает одинаковое время).
- $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$ — типичные классы сложности по возрастанию.

### Стек (Stack)

Организует хранение по принципу **LIFO** (Last In, First Out — «последний
пришёл, первый ушёл»).

```python
stack = []
stack.append(1)   # push (положить)   -> O(1)
stack.append(2)
stack.pop()        # pop (снять верхний) -> O(1) -> вернёт 2
```

> **Переполнение стека (stack overflow)** возникает, когда в стеке вызовов
> хранится больше информации, чем он может вместить (например, из-за слишком
> глубокой рекурсии).

### Очередь (Queue)

Работает по принципу **FIFO** (First In, First Out — «первый пришёл, первый
ушёл»). Операции `enqueue` и `dequeue` должны выполняться за $O(1)$.

```python
from collections import deque

queue = deque()
queue.append(1)      # enqueue -> O(1)
queue.append(2)
queue.popleft()      # dequeue -> O(1) -> вернёт 1
```

![Стек (LIFO) vs очередь (FIFO): push/pop сверху и enqueue/dequeue с концов](/kb-img/stack-queue.svg)

### Deque (двухсторонняя очередь)

**Deque** (double-ended queue) — структура, где можно добавлять и удалять
элементы с **обоих** концов.

```python
from collections import deque

dq = deque([1, 2, 3])
dq.appendleft(0)   # добавить слева
dq.append(4)        # добавить справа
dq.popleft()        # удалить слева
dq.pop()            # удалить справа
```

## Математическая основа

Обозначения сложности (при $n \to \infty$):

$$O(1) < O(\log n) < O(n) < O(n \log n) < O(n^2) < O(2^n)$$

## Лучшие практики и подводные камни

- ✅ Для очереди используйте `collections.deque`, а не `list` (`list.pop(0)` — это $O(n)$).
- ⚠️ Глубокая рекурсия ведёт к переполнению стека — в Python есть лимит (`sys.setrecursionlimit`).
- ✅ Выбирайте структуру по требуемому порядку доступа: стек (LIFO) vs очередь (FIFO).

## Примеры реальных кейсов

- **Обход в ширину (BFS):** очередь для перебора графа по уровням.
- **Отмена действий (undo):** стек истории операций.
- **Скользящее окно:** `deque` для эффективного максимума/минимума в окне.
