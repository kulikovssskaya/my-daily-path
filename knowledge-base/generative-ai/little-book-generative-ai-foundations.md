## 1. О книге и карта идей

**Автор:** Tianhua Chen, University of Huddersfield  
**Источник:** [arXiv:2605.29713](https://arxiv.org/abs/2605.29713), preprint, май 2026  
**Объём оригинала:** 178 страниц, 8 глав + приложения

### Что это за книга

Это **не** каталог нейросетевых архитектур и не гайд по Stable Diffusion / ChatGPT. Это компактный, но строгий **математический праймер**: автор выстраивает единую логическую цепочку от линейной алгебры до GAN и energy-based моделей, показывая, что за разными названиями стоят одни и те же операции — проекция, маргинализация, зашумление, оценка score, сравнение распределений.

Слово *«little»* в названии означает **узкий охват**, а не поверхностность: внутри выбранных тем автор даёт полные пошаговые выводы, а не рецепты «чёрных ящиков».

### Восемь сквозных математических принципов

| Принцип | Что делает в генеративных моделях |
|---------|-----------------------------------|
| **Латентные переменные** | Скрытые причины наблюдаемых данных (\(z \to x\)) |
| **Likelihood** | Обучение через \(\log p(x)\) — насколько данные правдоподобны |
| **Variational bounds (ELBO)** | Нижняя граница, когда \(\int p(x|z)p(z)\,dz\) не вычислить |
| **Инвертируемые преобразования** | Exact density: плотность через детерминант Якобиана |
| **Стохастическое зашумление** | Forward diffusion: структура → шум |
| **Score fields** | \(\nabla_x \log p(x)\) — куда двигаться, чтобы стать «более данными» |
| **Adversarial comparison** | GAN: учимся без явной плотности, через дискриминатор |
| **Energy landscapes** | \(p(x) \propto e^{-E(x)}\) — правдоподобие через скалярную энергию |

### Логика глав

Книга выстроена **по нарастанию сложности**, а не по хронологии изобретений:

```
PCA → Автоэнкодер → PPCA → VAE → DDPM →
Непрерывное время → Score-based → Flows / Autoregressive → GAN / WGAN / EBM
```

Линейная алгебра, теория вероятностей, исчисление и гауссова алгебра **вводятся по мере необходимости** внутри повествования, а не отдельным длинным введением.

### Как читать оригинал vs этот конспект

Оригинал содержит **полные выводы** (иногда на несколько страниц на одну формулу). Конспект сохраняет **результаты и интуицию**, опуская промежуточную алгебру. Для воспроизведения доказательств — оригинал или приложения A/B.

### Сквозная аналогия

- **PCA / автоэнкодер** — низкоразмерная карта данных с реконструкцией
- **PPCA / VAE** — карта стала вероятностной: сэмпл из prior → данные
- **Diffusion** — карта стирается шумом; модель учит обратное восстановление
- **Score-based** — в каждой точке стрелка «к более вероятным местам»
- **Flows** — готовая функция «шум → данные» за один проход
- **GAN** — эксперт отличает «настоящее» от «фейка» без формулы плотности
- **EBM** — высота в каждой точке; низины = правдоподобные данные

## 2. Глава 1: PCA и автоэнкодеры

### Зачем начинать с PCA

PCA — естественная точка входа по двум причинам:

1. **Мост к генеративным моделям.** Проекция → реконструкция → латентное пространство → вероятностная версия (PPCA) → VAE → diffusion. Одна и та же идея «сжать и восстановить» проходит через всю книгу в всё более гибких формах.
2. **Повторение линейной алгебры.** Матрицы, собственные векторы, ковариация, SVD — базовые инструменты для всех последующих глав.

### Матрица как линейное преобразование

Умножение \(y = Ax\) — не механическое правило, а **геометрическое изменение** вектора и координатной системы. Два эквивалентных взгляда:

- **Комбинация столбцов:** \(y = \sum_j x_j a_j\), где \(a_j\) — столбцы \(A\); выход строится из «направлений» матрицы.
- **Проекции на строки:** \(y_i = a_i^T x\) — каждая координата выхода измеряет выравнивание входа с \(i\)-й строкой.

Оба взгляда нужны для PCA: смена базиса (столбцы) и измерение разброса (проекции).

### Собственные векторы и собственные значения

Для квадратной матрицы \(A\): \(Av = \lambda v\). Собственный вектор \(v\) — направление, которое \(A\) **не поворачивает**, а только растягивает/сжимает в \(\lambda\) раз. Для симметричной ковариационной матрицы собственные векторы ортонормированы — это «естественные оси» разброса данных.

### PCA как максимизация дисперсии

Данные центрируются: \(\tilde{x} = x - \mu\). Ковариация:

\[
\Sigma = \frac{1}{N}\sum_{n=1}^{N} \tilde{x}_n \tilde{x}_n^T
\]

PCA ищет единичный вектор \(w\), максимизирующий \(\mathrm{Var}(w^T \tilde{x}) = w^T \Sigma w\). Решение: **главные компоненты = собственные векторы \(\Sigma\)**, упорядоченные по убыванию собственных значений (захваченная дисперсия).

Снижение размерности до \(k\):

- **Проекция (encode):** \(z = W_k^T \tilde{x}\), где столбцы \(W_k\) — top-\(k\) eigenvectors
- **Реконструкция (decode):** \(\hat{x} = W_k z + \mu\)
- **Explained variance ratio:** \(\lambda_i / \sum_j \lambda_j\) — доля дисперсии, сохранённая \(i\)-й компонентой

### PCA как смена базиса и SVD

Диагонализация \(\Sigma = Q \Lambda Q^T\) — **similarity transform**: полная дисперсия сохраняется, координаты становятся некоррелированными. Для центрированной матрицы данных \(X\) PCA эквивалентен SVD: главные направления = правые сингулярные векторы.

### От PCA к автоэнкодерам

PCA переформулируется как **encoder–decoder**:

\[
z = f_{\text{enc}}(x), \quad \hat{x} = f_{\text{dec}}(z), \quad \mathcal{L} = \|x - \hat{x}\|^2
\]

| Модель | Результат |
|--------|-----------|
| **Линейный автоэнкодер** с bottleneck размерности \(k\) | Восстанавливает **то же оптимальное подпространство**, что и PCA (Baldi & Hornik) |
| **Нелинейный автоэнкодер** | Сжимает данные на **изогнутых многообразиях** (manifolds), а не только на плоских подпространствах |

Глубокие автоэнкодеры (Hinton & Salakhutdinov) показали, что многослойные сети могут находить нелинейные представления, недоступные PCA. Однако без вероятностной структуры остаётся вопрос: **что значит «сэмплировать» из латентного пространства?** Произвольная точка \(z\) может декодироваться в бессмысленный \(x\). Это центральная мотивация перехода к PPCA и VAE — нужен prior, который определяет, какие \(z\) «допустимы».

### Ошибка реконструкции и оптимальность PCA

Минимизация \(\|x - \hat{x}\|^2\) при линейном encoder/decoder с bottleneck \(k\) эквивалентна поиску ортогонального проектора ранга \(k\), минимизирующего ошибку. Решение — проекция на top-\(k\) подпространство PCA. **Следствие:** если ваша цель — только сжатие и восстановление без генерации, PCA/линейный AE достаточны и интерпретируемы.

**Ключевое ограничение:** детерминистическая реконструкция не даёт полноценного **вероятностного** описания. Нет prior на латент, нет principled сэмплирования новых точек → мотивация Probabilistic PCA.

### Практические заметки (глава 1)

- **Explained variance:** правило «95% дисперсии» — эвристика; в генеративных моделях размерность латента выбирают по качеству реконструкции / генерации.
- **Нелинейные многообразия:** реальные данные лежат на низкоразмерных кривых в высокомерном пространстве — нелинейный автоэнкодер это эксплуатирует, но без вероятностной интерпретации.
- **Связь с diffusion-latents:** идея «сжать и восстановить» лежит в основе VAE-энкодеров в Stable Diffusion.

## 3. Глава 2: Probabilistic PCA

### PPCA — первый вероятностный генеративный модель

PPCA расширяет PCA, добавляя вероятностную структуру:

1. **Prior:** \(z \sim p(z) = \mathcal{N}(0, I)\)
2. **Decoder:** \(x \mid z \sim \mathcal{N}(Wz + \mu,\, \sigma^2 I)\)

Генерация: сэмплируем \(z\), затем \(x\) из условного гаусса. Наблюдение = линейное преобразование латента + изотропный шум.

### Четыре центральных объекта

| Объект | Формула / роль |
|--------|----------------|
| Prior \(p(z)\) | Априор на скрытые причины |
| Likelihood \(p(x|z)\) | Как латент порождает данные |
| Marginal \(p(x) = \int p(x|z)p(z)\,dz\) | Для обучения (MLE) |
| Posterior \(p(z|x)\) | Для инференса (какой \(z\) объясняет \(x\)) |

### Аналитическая разрешимость

Линейность + гауссовость → **все величины в замкнутой форме**. Маргинальная ковариация:

\[
\mathrm{Cov}(x) = WW^T + \sigma^2 I
\]

Интерпретация: **низкоранговая структура** (как в PCA, через \(W\)) + **изотропный шум** \(\sigma^2 I\). Posterior \(p(z|x)\) тоже гауссов — можно вычислить среднее и ковариацию аналитически (completing the square, приложение A).

### Три способа обучения

1. **Аналитический MLE** — через спектральное разложение \(\Sigma\); связь с классическим PCA (собственные векторы \(W\))
2. **Градиентный спуск** по \(\sum_n \log p(x_n)\)
3. **EM (Expectation–Maximisation):**
   - **E-step:** при фиксированных параметрах вычислить \(q(z|x) = p(z|x)\)
   - **M-step:** обновить \(W, \mu, \sigma^2\), максимизируя \(\mathbb{E}_{q}[\log p(x,z)]\)

EM раскрывает глубинную структуру: **чередование инференса по скрытым переменным и оптимизации параметров**.

Подробнее алгоритм EM для PPCA:

1. Инициализировать \(W, \mu, \sigma^2\)
2. **E-step:** для каждого \(x_n\) вычислить \(\mathbb{E}[z|x_n]\) и \(\mathbb{E}[zz^T|x_n]\) из гауссова posterior
3. **M-step:** обновить \(W = \big(\sum_n (x_n - \mu)\mathbb{E}[z|x_n]^T\big)\big(\sum_n \mathbb{E}[zz^T|x_n]\big)^{-1}\), затем \(\mu\) и \(\sigma^2\)
4. Повторять до сходимости

Эта схема E-step / M-step **повторяется** в более сложных моделях (GMM, HMM), но в PPCA все шаги аналитические.

### ELBO и неравенство Йенсена

Когда маргинализация по \(z\) трудна, вводят аппроксимацию \(q(z|x)\):

\[
\log p(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - \mathrm{KL}\bigl(q(z|x)\,\|\,p(z)\bigr) = \text{ELBO}
\]

Неравенство Йенсена: \(\log \mathbb{E}[f] \geq \mathbb{E}[\log f]\). В PPCA EM = подъём по ELBO при \(q = p(z|x)\) (tight bound).

### Ограничение PPCA → мост к VAE

PPCA вводит prior на \(z\), но при обучении **не регуляризует** агрегированное латентное пространство всех данных, чтобы оно совпадало с \(\mathcal{N}(0,I)\). Нет явного KL-члена для encoder'а. VAE решает это, добавив \(q_\phi(z|x)\) и KL в objective.

### Практические заметки (глава 2)

- **Completing the square** (приложение A): стандартный приём для вывода \(p(z|x)\) в гауссовых моделях.
- **EM vs gradient descent:** EM стабильнее на малых данных; SGD масштабируется на GPU.
- **Связь PPCA ↔ PCA:** при \(\sigma^2 \to 0\) PPCA → детерминистический PCA; \(\sigma^2\) — обучаемый параметр «размытия».
- **Первое появление ELBO:** в PPCA bound tight при \(q = p(z|x)\); в VAE — аппроксимация.

## 4. Глава 3: VAE

### Синтез двух линий развития

| Из PPCA | Из автоэнкодера |
|---------|-----------------|
| Prior, decoder, posterior, ELBO | Нелинейные encoder/decoder (нейросети) |
| Вероятностная генерация | Гибкое представление |

**VAE (Kingma & Welling, 2014):** encoder \(q_\phi(z|x)\), decoder \(p_\theta(x|z)\), prior \(p(z) = \mathcal{N}(0,I)\).

### Проблема intractable likelihood

В нелинейном случае:

\[
p_\theta(x) = \int p_\theta(x|z)\,p(z)\,dz, \quad p_\theta(z|x) = \frac{p_\theta(x|z)p(z)}{p_\theta(x)}
\]

ни одна величина **не вычисляется аналитически**. Решение — максимизация ELBO:

\[
\mathcal{L}(\theta,\phi; x) = \mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] - \mathrm{KL}\bigl(q_\phi(z|x)\,\|\,p(z)\bigr)
\]

| Член | Смысл |
|------|-------|
| **Reconstruction** | Декодер хорошо восстанавливает \(x\) из \(z\) |
| **KL** | Латентное пространство «похоже» на prior → можно сэмплировать \(z \sim p(z)\) и генерировать |

### Reparameterisation trick

Прямая выборка \(z \sim q_\phi(z|x)\) не дифференцируема. Трюк:

\[
z = \mu_\phi(x) + \sigma_\phi(x) \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0,I)
\]

Градиент течёт через \(\mu_\phi, \sigma_\phi\); шум \(\epsilon\) не зависит от параметров. Encoder и decoder обучаются **end-to-end** стохастическим градиентным спуском.

Альтернатива — REINFORCE / score function estimator для градиента через дискретную выборку, но reparameterisation имеет **меньшую дисперсию** градиента для гауссова \(q\).

### Декомпозиция ELBO и интерпретация

Перепишем ELBO:

\[
\mathcal{L} = \underbrace{\mathbb{E}_{q}[\log p_\theta(x|z)]}_{\text{качество реконструкции}} - \underbrace{\mathrm{KL}(q_\phi(z|x)\|p(z))}_{\text{«близость» латента к prior}}
\]

- Если KL = 0: латент идеально соответствует prior, но реконструкция может страдать
- Если KL велик: хорошая реконструкция, но латентное пространство «рваное» — генерация из prior даёт мусор
- Баланс двух членов — центральная практическая проблема VAE

### Главный инсайт

**VAE — не просто автоэнкодер.** Он учит представление, **совместимое с простым prior**, что делает генерацию principled: \(z \sim \mathcal{N}(0,I) \to x \sim p_\theta(x|z)\).

**Известные ограничения:** размытые сэмплы (Gaussian decoder), posterior collapse (KL → 0). Но математическая рамка ELBO + variational inference — фундамент, на котором строится понимание diffusion и других моделей.

### Практические заметки (глава 3)

- **\(\beta\)-VAE:** вес \(\beta > 1\) на KL усиливает disentanglement ценой реконструкции.
- **KL annealing:** постепенное увеличение веса KL предотвращает posterior collapse.
- **Amortized inference:** encoder предсказывает \(q(z|x)\) для любого \(x\) за один проход.
- **Связь с diffusion:** оба используют variational objectives; diffusion — последовательная версия с \(T\) шагами.

## 5. Глава 4: DDPM

### Парадигма: траектория зашумления

Diffusion models — одно из важнейших семейств современного генеративного ИИ (изображения, аудио, видео). Ключевая идея: **не генерировать за один шаг**, а постепенно превращать шум в структурированные данные через последовательность denoising-операций.

В отличие от PPCA/VAE (один латент \(z\)), diffusion работает с **целой траекторией** \(x_0, x_1, \ldots, x_T\):

- **Forward process \(q\)** (фиксирован): \(x_0\) (данные) → \(x_T\) (чистый шум)
- **Reverse process \(p_\theta\)** (обучаем): \(x_T\) → \(x_0\)

Физическая аналогия (Sohl-Dickstein et al.): капля чернил в воде рассеивается до однородности; модель учит **обратный** процесс — из однородного шума восстановить структуру.

### Forward process

Марковская цепь гауссовых переходов:

\[
q(x_t | x_{t-1}) = \mathcal{N}\bigl(\sqrt{1-\beta_t}\,x_{t-1},\; \beta_t I\bigr)
\]

где \(\beta_t\) — schedule шума. Ключевое свойство — **закрытая форма** без пошаговой симуляции:

\[
q(x_t | x_0) = \mathcal{N}\bigl(\sqrt{\bar{\alpha}_t}\,x_0,\; (1-\bar{\alpha}_t)I\bigr), \quad \bar{\alpha}_t = \prod_{s=1}^{t}(1-\beta_s)
\]

Репараметризация:

\[
x_t = \sqrt{\bar{\alpha}_t}\,x_0 + \sqrt{1-\bar{\alpha}_t}\,\epsilon, \quad \epsilon \sim \mathcal{N}(0,I)
\]

### Reverse process и ELBO

Обратные переходы \(p_\theta(x_{t-1}|x_t)\) — то, что учим. Вся конструкция — **латентная генеративная модель** с intractable \(\log p_\theta(x_0)\). ELBO раскладывается на сумму **локальных denoising-термов** по \(t\).

На каждом шаге ключевой объект — расхождение между learned \(p_\theta(x_{t-1}|x_t)\) и истинным posterior \(q(x_{t-1}|x_t, x_0)\). Posterior гауссов (forward гауссов), выводится аналитически, но зависит от **чистого** \(x_0\), которого нет при генерации.

### Noise prediction (Ho et al., 2020)

Репараметризация posterior через \(\epsilon\) сводит обучение к:

> Предсказать гауссов шум \(\epsilon\), который был добавлен к \(x_0\) для получения \(x_t\).

**Алгоритм обучения:**

1. \(x_0 \sim p_{\text{data}}\)
2. \(t \sim \mathrm{Uniform}\{1,\ldots,T\}\), \(\epsilon \sim \mathcal{N}(0,I)\)
3. \(x_t = \sqrt{\bar{\alpha}_t}\,x_0 + \sqrt{1-\bar{\alpha}_t}\,\epsilon\)
4. Минимизировать \(\|\epsilon - \epsilon_\theta(x_t, t)\|^2\)

**Генерация:** \(x_T \sim \mathcal{N}(0,I)\), затем \(T\) итераций denoising с обученным \(\epsilon_\theta\). На каждом шаге модель предсказывает шум, из которого вычисляется оценка \(x_{t-1}\) (или напрямую через формулу posterior mean).

### Почему diffusion работает

Интуиция автора: разбить сложную задачу «сгенерировать \(x_0\) из шума за один шаг» на \(T\) простых задач «немного убрать шум». Каждый шаг — локальная коррекция, которую нейросеть учится делать хорошо. Аналогия с curriculum learning: от грубого к тонкому.

Математически: ELBO для diffusion — сумма термов, каждый из которых похож на denoising autoencoder objective на своём уровне шума. Это объясняет, почему архитектуры diffusion (U-Net) похожи на denoising сети.

### Связь с предыдущими главами

DDPM продолжает линию PPCA → VAE: латентные переменные + variational objective. Но латент — **вся зашумлённая траектория**, а не один компактный \(z\). Практические улучшения (Nichol & Dhariwal): cosine schedule, learned variance.

### Практические заметки (глава 4)

- **Schedule \(\beta_t\):** linear, cosine — влияет на скорость зашумления; cosine часто лучше.
- **Параметризации:** predict \(\epsilon\), predict \(x_0\), predict score — эквивалентны; noise prediction наиболее стабильна.
- **DDPM как hierarchical VAE:** фиксированный encoder (forward), обучаемый decoder (reverse).
- **\(T = 1000\)** шагов при обучении; на инференсе — distillation до 20–50 шагов (за рамками книги).

## 6. Глава 5: Непрерывное время

### Зачем переходить к непрерывности

DDPM — конечное число шагов \(t = 1, \ldots, T\). Естественный вопрос: что при \(\Delta t \to 0\)? Ответ — **стохастические дифференциальные уравнения (SDE)** и эволюция плотности, что даёт более глубокое понимание diffusion и мост к score-based моделям.

### Язык непрерывного движения

- **Производная, дифференциальные уравнения:** как траектория \(x(t)\) эволюционирует во времени
- **Приращения:** \(\mathrm{d}x = v(x)\,\mathrm{d}t\) — детерминированное движение
- **Разложение Тейлора:** локальная линейная аппроксимация для малых \(\mathrm{d}t\)

### Три паттерна движения

| Процесс | Уравнение / суть |
|---------|------------------|
| **Детерминированный поток (ODE)** | \(\mathrm{d}x = v(x)\,\mathrm{d}t\); в линейном случае \(x(t) = e^{At}x(0)\) |
| **Brownian motion** | \(\mathrm{d}W_t\): гауссовы приращения, непрерывный случайный шум |
| **Ornstein–Uhlenbeck** | Дрейф к среднему + шум: mean-reverting процесс |

### От траекторий к плотности

Генеративное моделирование интересует не одна частица, а **как меняется распределение** \(p_t(x)\):

- **Liouville equation:** при детерминированном потоке плотность эволюционирует с сохранением «массы»
- **Change-of-variables (многомерный):** \(p_X(x) = p_Z(z)\,|\det J|^{-1}\); детерминант Якобиана = локальное сжатие/растяжение объёма
- **Divergence:** \(\nabla \cdot v\) — скорость изменения объёма в потоке
- **Fokker–Planck equation:** детерминированный транспорт + стохастическая диффузия (Brownian)

**Мост к главе 6:** Fokker–Planck связывает эволюцию \(p_t(x)\) с **градиентом log-плотности** \(\nabla_x \log p_t(x)\) — score function.

### Практические заметки (глава 5)

- **Continuous-time SDE** — основа score-based modelling (Song et al.) и ODE-samplers.
- **Liouville** — чистый транспорт (как flow в непрерывном времени); **Fokker–Planck** — транспорт + диффузия.
- **Ornstein–Uhlenbeck** — forward diffusion часто OU-подобен: данные «притягиваются» к шуму.
- **Дивергенция** \(\nabla \cdot v\) — trace Jacobian потока; связь с \(\log|\det J|\).

## 7. Глава 6: Score-based модели

### Смена перспективы

DDPM (глава 4) описывает diffusion как дискретную латентную цепь. Score-based подход задаёт **геометрический вопрос:**

> Если образец сейчас в точке \(x\), в каком направлении двигаться, чтобы стать более правдоподобным под \(p_{\text{data}}\)?

**Ответ:** score function \(\nabla_x \log p(x)\) — направление наискорейшего роста log-плотности. Плотность описывает, *где* масса; score — *куда* двигаться локально.

### Langevin dynamics

Комбинация score + гауссов шум:

\[
x_{t+1} = x_t + \frac{\eta}{2}\nabla_x \log p(x_t) + \sqrt{\eta}\,\xi_t, \quad \xi_t \sim \mathcal{N}(0,I)
\]

Дрейф к пикам плотности + шум для исследования пространства. Через Fokker–Planck: **стационарное распределение = целевое** \(p(x)\). Это principled способ сэмплирования, если score известен.

На практике Langevin с фиксированным \(\eta\) медленно смешивается в высоких размерностях; данные лежат на низкоразмерном многообразии — score вне многообразия нестабилен. Отсюда multi-scale подход ниже.

### Обучение score при неизвестной плотности

Истинный \(p_{\text{data}}(x)\) неизвестен → score \(\nabla_x \log p_{\text{data}}(x)\) тоже. Методы:

| Метод | Автор / идея |
|-------|--------------|
| **Score matching** | Hyvärinen: минимизировать Fisher divergence; integration by parts убирает неизвестный data score из loss |
| **Denoising score matching** | Vincent: зашумить \(x \to \tilde{x}\); обучить предсказывать \(\frac{x-\tilde{x}}{\sigma^2}\) = score сглаженной плотности \(p_\sigma(\tilde{x})\) |
| **Multi-scale score learning** | Song & Ermon: scores при разных \(\sigma\) — крупный шум даёт глобальную структуру, мелкий — детали |
| **Annealed Langevin dynamics** | Сэмплирование от большого шума к малому, используя multi-scale scores |

### Непрерывное время и SDE

Дискретная семья \(q_0, q_1, \ldots, q_T\) заменяется непрерывным путём \(p_t(x)\) через **forward SDE** (добавление шума во времени). **Reverse-time SDE** (Song et al.) содержит score \(\nabla_x \log p_t(x)\) как ключевой член — именно он направляет обратное движение от шума к данным.

### DDPM и score-based — два языка одной идеи

В DDPM предсказание шума \(\epsilon\) связано с conditional score:

\[
\nabla_{x_t} \log q(x_t|x_0) = -\frac{\epsilon}{\sqrt{1-\bar{\alpha}_t}}
\]

Marginal score \(\nabla_{x_t} \log q_t(x_t)\) получается усреднением по возможным \(x_0\) (как в denoising score matching).

| Взгляд | Акцент |
|--------|--------|
| **DDPM** | Дискретная латентная цепь, variational objective, noise prediction |
| **Score-based** | Геометрия зашумлённых плотностей, локальные направления, SDE |

**Общая идея:** forward process создаёт иерархию зашумлённых распределений; обучение оценивает локальные поправки; генерация = шум + повторные поправки.

### Практические заметки (глава 6)

- **Low-dimensional manifolds:** multi-scale noise «раздувает» многообразие данных, делая score learnable.
- **NCSN:** score network с conditioning на уровень шума \(\sigma\) или время \(t\).
- **Probability flow ODE:** детерминированный путь с теми же маргиналами — ODE-samplers без стохастики.
- **Annealed Langevin:** от большого \(\sigma\) к малому — curriculum для сэмплирования.

## 8. Глава 7: Exact density

### Другая парадигма

VAE и diffusion работают с approximate likelihood (ELBO) или score. **Normalising flows** и **autoregressive models** дают **точный** \(\log p(x)\) по конструкции — это принципиально иной trade-off: структурные ограничения в обмен на tractability.

### Normalising Flows

**Идея:** простое базовое распределение \(p_Z(z_0)\) (обычно \(\mathcal{N}(0,I)\)) преобразуется в сложное \(p_X(x)\) через цепочку дифференцируемых **инвертируемых** отображений \(f_1, \ldots, f_K\):

\[
z_0 \xrightarrow{f_1} z_1 \xrightarrow{f_2} \cdots \xrightarrow{f_K} x
\]

**Change-of-variables (полная цепочка):**

\[
\log p_X(x) = \log p_Z(z_0) - \sum_{k=1}^{K} \log\bigl|\det J_{f_k}(z_{k-1})\bigr|
\]

**Требования к каждому слою:**

1. **Инвертируемость** — можно пройти в обе стороны
2. **Сохранение размерности** — \(\dim z = \dim x\)
3. **Трактируемый** \(\log|\det J|\) — иначе likelihood не вычислить

**Практические архитектуры:**

| Архитектура | Механизм |
|-------------|----------|
| **Planar flows** | Rank-one возмущение; простой Jacobian |
| **Affine coupling** (RealNVP) | Половина координат трансформируется, вторая — conditioning; Jacobian треугольный |
| **Glow** | Coupling + invertible 1×1 convolutions для mixing координат |

**Генерация:** \(z_0 \sim p_Z\) → один детерминированный проход → \(x\). Без MCMC, без ELBO, без численного интегрирования. **Контраст с diffusion:** flows — детерминированный map; diffusion — стохастический reverse process.

Coupling layer подробнее: вход \(x\) разбивается на \((x_1, x_2)\). Трансформируется только \(x_2\):

\[
y_1 = x_1, \quad y_2 = x_2 \odot \exp(s(x_1)) + t(x_1)
\]

где \(s, t\) — нейросети. Обратное: \(x_2 = (y_2 - t(y_1)) \odot \exp(-s(y_1))\). Jacobian блочно-треугольный → \(\log|\det J| = \sum_i s_i(x_1)\). Это делает likelihood **точным и быстрым**.

### Autoregressive models

Вместо глобального преобразования — **chain rule** вероятности:

\[
p(x) = \prod_{i=1}^{d} p(x_i \mid x_{<i})
\]

Каждый фактор — условное распределение, параметризованное нейросетью \(f_\theta(x_{<i})\).

| Аспект | Normalising Flows | Autoregressive |
|--------|-------------------|----------------|
| Механизм | Инвертируемые map'ы | Упорядоченные conditionals |
| \(\log p(x)\) | Через Якобиан | Через сумму \(\log p(x_i|x_{<i})\) |
| **Сэмплирование** | Один параллельный проход | **Последовательное:** \(x_1 \to x_2 \to \cdots \to x_d\) |
| **Обучение** | Exact MLE | Exact MLE; **параллельно** (все \(x_i\) известны из данных) |

**Masking** (MADE, PixelCNN, WaveNet): в архитектуре блокируются связи так, чтобы \(x_i\) зависел только от \(x_{<i}\), а не от \(x_{\geq i}\). Треугольная структура зависимостей — аналог треугольного Jacobian в coupling flows.

**Вывод:** exact likelihood достижим при жёстко структурированных зависимостях.

### Практические заметки (глава 7)

- **Flows:** coupling без mixing (permutations, 1×1 conv) — ограниченная выразительность.
- **GPT — autoregressive** по токенам: \(p(x_t | x_{<t})\) через transformer.
- **PixelCNN / WaveNet:** AR для изображений и аудио; медленная генерация, но exact likelihood.
- **Bits per dimension:** \(-\mathbb{E}[\log p(x)] / (d \ln 2)\) — метрика для exact density models.

## 9. Глава 8: GAN, WGAN, EBM

### За пределами tractable likelihood

Предыдущие главы в той или иной мере опирались на likelihood (точный, variational или score-based). GAN, WGAN и EBM показывают, что генеративное обучение возможно через **сравнение**, **геометрическое расстояние** или **энергетический ландшафт** — без явной оценки \(p(x)\).

### GAN — обучение через сравнение (Goodfellow et al., 2014)

**Minimax игра:** Generator \(G_\theta: z \to x\) vs Discriminator \(D: x \to [0,1]\).

\[
\min_G \max_D \; \mathbb{E}_{p_{\text{data}}}[\log D(x)] + \mathbb{E}_{p_\theta}[\log(1-D(x))]
\]

**Оптимальный дискриминатор** (при фиксированном \(G\)):

\[
D^*(x) = \frac{p_{\text{data}}(x)}{p_{\text{data}}(x) + p_\theta(x)}
\]

Интерпретация: \(D^*\) — локальный **оценщик density ratio**, хотя ни одна плотность явно не вычисляется.

При \(D = D^*\): обучение \(G\) эквивалентно минимизации **Jensen–Shannon divergence** \(JS(p_{\text{data}}\|p_\theta)\). На практике используют **non-saturating loss** для более сильных градиентов генератора.

**Плюсы:** генерация за 1 проход, высокое качество (исторически для изображений). **Минусы:** нестабильность, mode collapse, отсутствие likelihood, сложная диагностика.

### Wasserstein GAN — геометрическое расстояние (Arjovsky et al.)

Замена overlap-based дискриминации на **1-Wasserstein distance** (Earth Mover's Distance): минимальная «стоимость» переноса массы из \(p_\theta\) в \(p_{\text{data}}\).

- **Critic** \(f\) (не дискриминатор) — real-valued, **1-Lipschitz**
- Dual formulation: через supremum над критиками
- **Gradient penalty** (Gulrajani et al.) — стабилизация, принуждение к Lipschitz

WGAN оценивает, как probability mass должна **перемещаться** в пространстве данных, а не просто «реал vs фейк».

### Energy-Based Models (EBM)

\[
p_\theta(x) = \frac{1}{Z_\theta}\exp\bigl(-E_\theta(x)\bigr), \quad Z_\theta = \int \exp(-E_\theta(x))\,dx
\]

| Низкая \(E_\theta(x)\) | Высокая \(E_\theta(x)\) |
|------------------------|-------------------------|
| Правдоподобные данные | Неправдоподобные конфигурации |

\(Z_\theta\) (partition function) обычно **не вычислим** — главная трудность EBM.

**Contrastive gradient (ML для EBM):**

\[
\nabla_\theta \mathbb{E}_{p_{\text{data}}}[\log p_\theta] = -\mathbb{E}_{p_{\text{data}}}[\nabla_\theta E] + \mathbb{E}_{p_\theta}[\nabla_\theta E]
\]

- **Positive phase:** понижает энергию реальных данных
- **Negative phase:** повышает энергию сэмплов из модели

**Проблема:** negative phase требует сэмплирования из \(p_\theta\) — само по себе трудная задача (Langevin, MCMC). Циклическая зависимость: чтобы учить энергию, нужны сэмплы; чтобы сэмплировать, нужна хорошая энергия.

Contrastive divergence (Hinton): вместо полного сэмплирования — несколько шагов Langevin/M Gibbs от данных. Приближение negative phase, но biased.

### Связь EBM ↔ Score ↔ Diffusion

Фундаментальная тождество:

\[
\nabla_x \log p(x) = -\nabla_x E(x)
\]

| Подход | Как задаёт «направление к данным» |
|--------|-----------------------------------|
| **EBM** | Скалярная энергия \(E(x)\) → score через \(\nabla_x\) |
| **Score-based** | Векторное поле \(s_\theta(x) \approx \nabla_x \log p(x)\) напрямую |
| **Diffusion** | Time-dependent score \(s_\theta(x,t) \approx \nabla_x \log p_t(x)\) на иерархии зашумлённых \(p_t\) |

**Инсайт автора:** diffusion = **стабильная multi-scale energy-gradient learning** без прямого negative phase EBM.

### Практические заметки (глава 8)

- **Mode collapse (GAN):** генератор находит узкий набор образцов; WGAN-GP частично решает.
- **JS vs KL:** JS непрерывен при disjoint supports; KL был бы бесконечен.
- **WGAN-GP:** gradient penalty \((\|\nabla f\|_2 - 1)^2\) — стандарт стабилизации.
- **Boltzmann machines:** ранний EBM с бинарными скрытыми переменными.

| Модель | Likelihood | Латент | Генерация | Главная идея |

### Единая карта (Closing Remarks)

Все подходы — вариации одних операций:

```
представление → преобразование → маргинализация → аппроксимация →
зашумление/денойзинг → эволюция плотности → score →
likelihood → сравнение распределений → формирование энергии
```

Flow matching, rectified flows, consistency models — **ускорение и уточнение** diffusion/transport, не новая математика.

### Два оси классификации моделей

**Ось 1 — как оценивается обучение:**

| Тип | Модели |
|-----|--------|
| Exact likelihood | Flows, Autoregressive |
| Approximate likelihood (ELBO) | PPCA, VAE, DDPM |
| Score / gradient matching | Score-based, Denoising score matching |
| Implicit (без плотности) | GAN, WGAN |
| Unnormalized (partition function) | EBM |

**Ось 2 — как происходит генерация:**

| Тип | Модели |
|-----|--------|
| 1 проход | GAN, Flows |
| Decode из латента | VAE |
| Последовательно по компонентам | Autoregressive |
| Итеративный denoising / Langevin | DDPM, Score-based, EBM |

**Порядок изучения:** PCA → PPCA (ELBO аналитически) → VAE → DDPM ↔ score-based (как два языка) → flows/AR → GAN/EBM.

**Выбор модели:**

| Задача | Подход |
|--------|--------|
| Нужен exact \(\log p(x)\) | Flows, autoregressive |
| Максимальное качество, likelihood не нужен | Diffusion / score-based |
| Компактный латент, интерполяция | VAE |
| Быстрая генерация (1 проход) | GAN, flows, AR |
| Interpretable «энергия» конфигурации | EBM (сложное обучение) |

| Модель | Формула |
|--------|---------|
| PCA | \(\Sigma = \frac{1}{N}\sum \tilde{x}\tilde{x}^T\); PC = eigenvectors \(\Sigma\) |

Книга — **фундамент для понимания**, не frontier survey. После неё проще читать статьи по flow matching, consistency models, DiT и др.

### Приложения оригинала

- **Приложение A (Gaussian Algebra):** completing the square — ключ к posterior в PPCA, VAE, diffusion.
- **Приложение B (Diffusion Reverse-Posterior):** полный вывод \(q(x_{t-1}|x_t, x_0)\) для DDPM.

Data scientist / ML engineer, который хочет понять математику за diffusion и VAE; студент курса по generative models; исследователь, которому нужна карта связей между семействами моделей.
