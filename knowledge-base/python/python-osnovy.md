# Python — Основы

> `#Python` `#DataScience` `#Основы`
>
> Базовый Python, необходимый для анализа данных и ML: структуры данных,
> управляющие конструкции, функции, файлы и работа в командной строке.

## Ключевые концепции

- **Операторы:** `%` — остаток от деления, `//` — целочисленное деление.
- **Коллекции:** `list` (изменяемый), `tuple` (неизменяемый), `set` (уникальные), `dict` (ключ-значение).
- **Управление потоком:** `for`, `while`, `try/except/finally`, `continue`, `pass`.
- **Функции** и **рекурсия**, декомпозиция задач.
- **Comprehensions** для списков/множеств/словарей.
- **Файлы** через менеджер контекста `with`.

## Подробное объяснение

### Числа, строки, вывод

```python
7 % 3        # остаток от деления -> 1
7 // 3       # целочисленное деление -> 2
int(x), float(x)   # приведение типов
"а" + "б"          # конкатенация строк
'Никогда не говори "Никогда"'  # кавычки внутри строки

print(1, 2, 4, 7, sep=",")   # sep — разделитель -> 1,2,4,7
print("текст", end="")        # end — чем заканчивается вывод (по умолчанию \n)
```

### Циклы и обработка ошибок

```python
for i in range(2, 5, 1):   # range(start, stop, step); i — счётчик
    print(i)

while условие:             # выполняется, пока условие истинно
    ...

# Обработка ошибок
try:
    risky()
except ValueError:         # можно указать ожидаемый тип ошибки
    handle()
finally:
    cleanup()              # выполняется в любом случае
```

- `continue` — переходит к началу цикла, пропуская оставшийся блок.
- `pass` — «ничего не делать», пустой блок-заглушка.

### Списки (`list`)

```python
l = [1, 2, 3]
len(l)              # длина
l.append(42)        # добавить в конец
l1.extend(l2)       # объединить (изменяет l1); либо l3 = l1 + l2
sorted(l)           # новая отсортированная копия
sorted(l, reverse=True)
del l[0]            # удалить элемент по индексу

# Срезы (слайсинг)
l[2:-2:3]           # с 3-го до предпоследних-2, шаг 3
l[::-1]             # в обратном порядке
```

### Кортежи (`tuple`)

Неизменяемая последовательность — занимает меньше памяти и быстрее списка.

```python
t = ()                 # пустой
t = (1,)               # из одного элемента (запятая обязательна!)
t = tuple([1, 10, 0])  # из списка
t = tuple("tururum")   # из строки
```

Поддерживает индексацию, срезы, конкатенацию, `min/max/len`. Менять элементы нельзя; можно преобразовать в `list`.

### Множества (`set`)

Изменяемая **неупорядоченная** коллекция **уникальных** элементов.

```python
s = set()          # пустое (ВНИМАНИЕ: {} создаёт dict, а не set!)
s = {1, 2, 10}
s.add(5)           # добавить
s.discard(5)       # удалить
2 in s             # проверка вхождения

# Операции над множествами
a & b   # a.intersection(b)          — пересечение
a | b   # a.union(b)                 — объединение
a - b   # a.difference(b)            — разность
a ^ b   # a.symmetric_difference(b)  — симметричная разность
```

### Словари (`dict`)

Неупорядоченная изменяемая коллекция пар «ключ-значение» с уникальными ключами. Ключами могут быть строки, числа, кортежи; значениями — что угодно (в т.ч. списки).

```python
d = {"facebook": 120, "youtube": 299}
d["facebook"]          # доступ по ключу
d[1] = 115             # создать/изменить
del d[1]               # удалить

d.keys()               # ключи
d.values()             # значения
d.items()              # пары (ключ, значение)
d.get(key, default)    # безопасный доступ с значением по умолчанию

for k, v in d.items():
    print(f"{k}: {round(v, 2)}")
```

### Функции и рекурсия

```python
def f(a, b):           # с параметрами
    return a + b       # return забирает значение и выходит из функции

def g():               # без параметров
    ...
```

- Переменные внутри функции недоступны снаружи (область видимости).
- `return` может вернуть несколько значений (кортежем).
- **Рекурсия** — функция вызывает саму себя. Активно расходует память (стек вызовов).
- Встроенные функции для коллекций: `sum()`, `min()`, `max()`, `len()`.

### Работа со строками

```python
fio[0]              # доступ по индексу
s.split()           # разделение по пробелам -> list
s.lower(), s.upper()
s.find("под")       # индекс первого вхождения; -1 если не найдено
",".join(items)     # склейка списка строк через разделитель
```

> **Метод** (в отличие от функции) привязан к объекту и не может быть вызван сам по себе: `s.split()`, `l.append(...)`.

### Comprehensions (генераторы)

```python
items = [x.lower() for x in items]          # list comprehension
string_set = {str(x) for x in range(1, 11)} # set comprehension
squares = {x: x * 5 for x in range(1, 6)}   # dict comprehension
```

### Чтение файлов

```python
# Менеджер контекста автоматически закроет файл
with open("data.txt", "r", encoding="utf-8") as file:
    content = file.read()      # весь файл строкой
    # file.readline()  — одна строка
    # file.readlines() — список строк
```

### `zip`

Проходит одновременно по нескольким итерируемым объектам, объединяя их в кортежи. Останавливается по самой короткой последовательности.

```python
for a, b in zip(list1, list2):
    ...
```

## Практическая реализация

Пример: частотность значений и вывод процентов.

```python
frequency_dict = {"facebook": 120, "youtube": 299, "vk": 81}
total = sum(frequency_dict.values())

for name, count in frequency_dict.items():
    percent = count / total * 100
    print(f"{name}: {round(percent, 2)}%")
```

## Лучшие практики и подводные камни

- ⚠️ `{}` создаёт **пустой словарь**, а не множество. Для пустого множества — `set()`.
- ⚠️ Кортеж из одного элемента требует запятой: `(1,)`, иначе это просто число в скобках.
- ⚠️ `l1.extend(l2)` и `l1 += l2` изменяют `l1` на месте; для новой копии используйте `l1 + l2`.
- ✅ Всегда открывайте файлы через `with` — гарантированное закрытие.
- ✅ Указывайте `encoding="utf-8"` при чтении текстовых файлов.
- ✅ Используйте f-строки для форматирования: `f"{x:0.3f}"`.
- 💡 Рекурсия расходует стек — для больших глубин предпочитайте итеративные решения.

## Алгоритмы: поиск и сортировка

- **Линейный поиск** — перебор по индексу до совпадения. Медленный: $O(n)$.
- **Бинарный поиск** — на отсортированном массиве делим пополам, ищем в нужной половине. Быстрый: $O(\log n)$.
- **Сортировка пузырьком** — поочерёдно сравниваем соседей за несколько проходов. $O(n^2)$.
