# Modeling — Проверка гипотез и мониторинг

> `#Statistics` `#ML` `#Python` `#scipy`
>
> Статистическая проверка гипотез при сравнении групп и базовый мониторинг
> моделей в проде.

## Ключевые концепции

- **Гипотеза** — утверждение, требующее доказательства.
- **Нулевая (H₀)** и **альтернативная (H₁)** гипотезы.
- **p-value** — вероятность ошибиться, отвергнув H₀ (порог обычно $\alpha = 5\%$).
- **Параметрические критерии:** t-критерий Стьюдента / Уэлча (нужна нормальность).
- **Непараметрические критерии:** Манна-Уитни, Уилкоксона (без нормальности).
- **Мониторинг моделей:** Grafana, Docker Compose.

## Подробное объяснение

### Гипотезы

**Гипотеза** — предположение, которое (в отличие от аксиом) требует доказательства.

Этапы:
1. Сформулировать гипотезу (например, «женщины живут дольше мужчин»).
2. Выделить:
   - **нулевую (H₀)** — различий между группами **нет**;
   - **альтернативную (H₁)** — различия **есть**.

**p-value** — вероятность ошибиться, если отвергнуть H₀. Порог значимости обычно
$\alpha = 5\%$. Если $p < \alpha$ — отвергаем нулевую гипотезу.

### Выбор критерия

| Условия | Критерий | Функция scipy |
|---------|----------|---------------|
| Нормальность + равные дисперсии, независимые | t-критерий Стьюдента | `stats.ttest_ind` |
| Нормальность, дисперсии **не** равны, независимые | t-критерий Уэлча | `stats.ttest_ind(..., equal_var=False)` |
| Нормальность, зависимые (парные) | Парный t-критерий | `stats.ttest_rel` |
| **Не** нормальные, независимые | Манна-Уитни | `stats.mannwhitneyu` |
| **Не** нормальные, зависимые | Уилкоксона | `stats.wilcoxon` |

Проверки-предпосылки:

- **Тест Шапиро-Уилка** — проверяет нормальность распределения (наиболее эффективный).
- **Тест Левена** — проверяет равенство дисперсий двух выборок.

### Практика: проверка предпосылок

```python
from scipy import stats

# Нормальность (H0: распределение нормальное)
stats.shapiro(df.men)
stats.shapiro(df.women)

# Равенство дисперсий (H0: дисперсии равны)
stats.levene(df.men, df.women)
```

### Параметрические критерии

```python
# t-критерий Стьюдента (независимые выборки, равные дисперсии)
stats.ttest_ind(df.men, df.women)

# t-критерий Уэлча (равенство дисперсий НЕ подтвердилось)
stats.ttest_ind(df.men, df.women, equal_var=False)

# Односторонняя проверка: среднее первой выборки БОЛЬШЕ второй
stats.ttest_ind(df.men, df.women, alternative="greater")

# Парный t-критерий (зависимые выборки одинакового размера)
# сначала проверяем нормальность: stats.shapiro(df2.pre) -> p > 5% -> применяем
stats.ttest_rel(df2.pre, df2.post, alternative="less")
```

> Если $p < 5\%$ — отвергаем H₀ (различия значимы).

### Непараметрические критерии

Применяются, когда нормальность **не** подтверждена.

```python
# Манна-Уитни (независимые, ненормальные). H0: распределения равны
stats.mannwhitneyu(df1, df2, alternative="greater")

# Ранговый тест Уилкоксона (зависимые пары, ненормальные).
# H0: выборки из одного распределения
stats.wilcoxon(df.before, df.after, alternative="greater")
```

## Мониторинг моделей

Отслеживание работы модели в проде — часть **MLOps**.

- **Grafana** — современная система визуализации и наблюдения (метрики, дашборды).
- Группа связанных сервисов описывается файлом `docker-compose.yml`.

```bash
docker-compose up            # запуск сервисов
docker-compose up -d         # в фоновом режиме
docker-compose stop          # остановка
docker ps -a                 # id всех контейнеров
docker rm <id>               # удалить контейнер
```

## Математическая основа

**t-статистика** для сравнения средних:

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$$

Решение принимается по p-value: если $p < \alpha$, отвергаем $H_0$.

## Лучшие практики и подводные камни

- ✅ Всегда проверяйте предпосылки (нормальность → Шапиро, дисперсии → Левен) **до** выбора критерия.
- ⚠️ Нельзя применять t-критерий к ненормальным данным — используйте Манна-Уитни/Уилкоксона.
- ⚠️ Парные тесты требуют выборок **одинакового размера** с соответствием наблюдений.
- ⚠️ У Манна-Уитни H₀ — о равенстве **распределений**, а не средних.
- ✅ Указывайте `alternative` для односторонних гипотез (`less` / `greater`).
