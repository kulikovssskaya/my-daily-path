## 1. Основы и парадигмы обучения

### 1.1 Что такое обучение с учителем (supervised)?
Модель учится на **размеченных** данных: каждый пример — это пара «вход →
ожидаемый выход (метка)». Цель — отобразить входы в выходы. Примеры:
классификация (детекция спама), регрессия (прогноз цены дома).

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

iris = load_iris()
X, y = iris.data, iris.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
clf = DecisionTreeClassifier()
clf.fit(X_train, y_train)
print(clf.score(X_test, y_test))
```

### 1.2 Что такое обучение без учителя (unsupervised)?
Работа с **неразмеченными** данными: алгоритм ищет скрытые паттерны или
группировки. Применяется для кластеризации и снижения размерности.

```python
from sklearn.datasets import load_iris
from sklearn.cluster import KMeans

X = load_iris().data
kmeans = KMeans(n_clusters=3)
kmeans.fit(X)
print(kmeans.labels_)
```

### 1.3 Что такое переобучение и как его предотвратить?
Переобучение (overfitting) — модель заучивает шум и детали обучающих данных так,
что качество на новых данных падает. Профилактика: регуляризация, больше данных,
отбор признаков, кросс-валидация, ранняя остановка (для нейросетей), упрощение
модели.

### 1.4 Что такое регуляризация?
Техника снижения сложности модели и борьбы с переобучением через штраф на
параметры. Основные типы — L1 (Lasso) и L2 (Ridge).

```python
from sklearn.linear_model import Ridge
ridge = Ridge(alpha=1.0)
ridge.fit(X_train, y_train)
print(ridge.score(X_test, y_test))
```

### 1.5 Что такое компромисс смещение-разброс (bias-variance)?
Баланс между слишком простой моделью (высокое смещение, недообучение) и слишком
сложной (высокий разброс, переобучение). Цель — низкие и смещение, и разброс.

![Компромисс смещение–разброс: смещение² убывает, разброс растёт, суммарная ошибка имеет минимум](/kb-img/bias-variance.svg)

### 1.6 Что такое отбор признаков (feature selection)?
Выбор наиболее важных переменных для обучения — снижает переобучение и
вычисления, повышает интерпретируемость.

```python
from sklearn.feature_selection import SelectKBest, f_classif
selector = SelectKBest(score_func=f_classif, k=2)
X_new = selector.fit_transform(X, y)
```

### 1.7 Как работает случайный лес (Random Forest)?
Ансамблевый метод: строит множество деревьев на бутстрап-выборках и усредняет их
предсказания — повышает точность и снижает переобучение.

```python
from sklearn.ensemble import RandomForestClassifier
rf = RandomForestClassifier(n_estimators=100)
rf.fit(X_train, y_train)
print(rf.score(X_test, y_test))
```

### 1.8 Что такое метод опорных векторов (SVM)?
Алгоритм для классификации и регрессии, находящий оптимальную гиперплоскость,
которая максимизирует зазор между классами.

```python
from sklearn.svm import SVC
svm = SVC(kernel="linear")
svm.fit(X_train, y_train)
```

### 1.9 Что такое нейронные сети?
Вычислительные модели, вдохновлённые мозгом: связанные слои узлов (нейронов).
Применяются в обучении с учителем и без, особенно сильны в сложных задачах.

![Полносвязная нейросеть: входной слой, скрытые слои и выходной слой, соединённые взвешенными рёбрами](/kb-img/neural-network.svg)

### 1.10 Что такое dropout в нейросетях?
Регуляризация: часть нейронов случайно обнуляется при обучении — предотвращает
переобучение.

```python
from keras.layers import Dropout
model.add(Dropout(0.5))
```

### 1.11 Что такое ранняя остановка (early stopping)?
Обучение прекращается, когда качество на валидации перестаёт улучшаться — защита
от переобучения.

### 1.12 Что такое обрезка (pruning) деревьев решений?
Удаление частей дерева, не дающих дополнительной предсказательной силы, чтобы
избежать переобучения.

### 1.13 Приведите пример transfer learning.
Использование предобученной VGG16 (на ImageNet) как экстрактора признаков для
своей задачи классификации изображений.

```python
from tensorflow.keras.applications import VGG16
model = VGG16(weights="imagenet", include_top=False)
```

### 1.14 Что такое автоэнкодер?
Нейросеть без учителя для обучения сжатых представлений данных — обычно для
снижения размерности или шумоподавления.

### 1.15 Что такое early stopping в нейросетях?
Стратегия регуляризации: обучение останавливается при прекращении улучшения на
валидации.

### 1.16 Что такое dropout (ещё раз)?
Метод регуляризации: случайные нейроны обнуляются при обучении — снижает
переобучение и улучшает обобщение.

### 1.17 Разница между обучением с учителем и без?
С учителем — размеченные данные; без учителя — поиск структуры в неразмеченных.

### 1.18 Что такое дрейф признаков (feature drift)?
Изменение статистических свойств входных признаков со временем — может ухудшать
качество модели.

### 1.19 Что такое дрейф концепции (concept drift)?
Изменение статистической связи между входом и выходом со временем — влияет на
предсказания.

### 1.20 Что такое полу-контролируемое обучение (semi-supervised)?
Обучение на небольшом объёме размеченных данных плюс большом объёме
неразмеченных.

### 1.21 Что такое активное обучение (active learning)?
Модель интерактивно запрашивает у человека/оракула метки для новых точек, повышая
эффективность обучения.

### 1.22 Что такое label smoothing?
Регуляризация: целевые метки «сглаживают», чтобы избежать переуверенности модели;
частое в deep learning.

### 1.23 Что такое XGBoost и почему он популярен?
Эффективная оптимизированная реализация градиентного бустинга с параллелизацией,
регуляризацией, обработкой пропусков. Популярен за стабильно высокую точность,
гибкость гиперпараметров, работу с большими данными и победы в соревнованиях.

```python
import xgboost as xgb
model = xgb.XGBClassifier()
model.fit(X_train, y_train)
```

### 1.24 Регуляризация L1 и L2 — как помогают?
**L1 (Lasso):** добавляет к функции потерь абсолютные значения весов → разрежённость
(зануляет малозначимые веса, отбор признаков). **L2 (Ridge):** добавляет квадрат
весов → штрафует большие веса, снижает переобучение. Итог — лучшее обобщение и
более простые модели.

```python
from sklearn.linear_model import Lasso, Ridge
lasso = Lasso(alpha=0.1)
ridge = Ridge(alpha=1.0)
```

### 1.25 Как работает early stopping и почему улучшает обобщение?
Отслеживает качество на валидации; обучение останавливается, если потери не
улучшаются заданное число эпох (**patience**). Не даёт модели «заучить»
обучающие данные; выбирается точка наилучшего обобщения. Применяется в deep
learning, бустинге и любом итеративном обучении.

### 1.26 Transfer learning (продвинутый контекст).
Перенос знаний предобученной модели (часто на огромном датасете) на новую
похожую задачу: **fine-tuning** (разморозить часть/все слои и дообучить) или
**feature extraction** (фиксированный экстрактор + новые слои). В NLP и CV даёт
сильные результаты при малых данных.

### 1.27 Что такое label propagation в semi-supervised?
Присваивает метки неразмеченным точкам на основе их близости к размеченным —
графовый подход распространения меток по датасету.

### 1.28 Что такое вариационные автоэнкодеры (VAE)?
Генеративные нейросети без учителя: кодируют вход в вероятностное латентное
пространство и декодируют обратно — позволяют генерировать новые примеры,
интерполировать, вероятностно рассуждать.

### 1.29 Что такое доменная адаптация (domain adaptation)?
Частный случай transfer learning: перенос знаний между различающимися, но
связанными распределениями — подстройка модели при сдвиге распределений между
обучением и продом.

### 1.30 Bagging vs boosting на практике.
**Bagging** (Random Forest) — снижает разброс усреднением независимых моделей.
**Boosting** (XGBoost) — снижает смещение, строя последовательные модели, каждая
исправляет ошибки предыдущей; часто сильнее на табличных данных.

### 1.31 Что такое self-supervised learning?
Использует собственную структуру данных для supervision: модель сама генерирует
метки (например, предсказание замаскированных слов в BERT или следующего кадра).
Применяется для предобучения в NLP, CV, audio.

### 1.32 Что такое активный сэмплинг (active sampling)?
Стратегия отбора данных: модель находит точки, разметка которых сильнее всего
улучшит её. Важно, когда разметка дорога (медицина, юридические документы).
Техники: uncertainty sampling, query-by-committee, expected model change,
diversity sampling.

### 1.33 Что такое knowledge transfer в multi-task learning?
В многозадачном обучении (MTL) обучение одной задаче улучшает другую за счёт
общих представлений. Пример: сеть детектирует «машины» и «грузовики» — знание
формы колёс помогает обеим. Плюсы: лучшее обобщение, эффективность по данным.

### 1.34 Что такое Elastic Net?
Комбинация штрафов L1 (Lasso) и L2 (Ridge) в регрессии: L1 зануляет часть
коэффициентов (отбор), L2 сжимает все (против переобучения). Полезна при многих
коррелированных предикторах.

### 1.35 Что такое полиномиальная регрессия?
Регрессия, где входные переменные возводятся в степени для захвата нелинейных
трендов (например, парабола). Высокие степени рискуют переобучением —
нужна регуляризация/кросс-валидация.

### 1.36 Ограничения Deep Learning?
Требует много размеченных данных; вычислительно дорого; «чёрный ящик» (низкая
интерпретируемость); уязвимость к состязательным атакам; риск переобучения без
регуляризации; сложности обновления/контроля больших моделей в проде.

### 1.37 Когда полезно активное обучение?
Когда разметка дорога/дефицитна — для максимизации эффективности (медицинский ИИ,
редкие события). Модель запрашивает метки для самых неопределённых примеров.

### 1.38 Что такое batch normalization и почему она критична?
Нормализует промежуточные активации в сети, стабилизируя и ускоряя обучение.
Плюсы: быстрая сходимость, высокие learning rate, эффект регуляризации, меньше
чувствительности к инициализации.

### 1.39 Как dropout помогает против переобучения?
Случайно отключает долю нейронов на каждом проходе, заставляя представления быть
избыточными и не давая одному пути доминировать. Итог — заметный рост обобщения,
особенно в больших сетях.

### 1.40 Что такое early stopping (ещё раз)?
Останавливает обучение, когда отслеживаемая метрика (например, val loss) не
улучшается заданное число итераций (patience). Снижает переобучение, сохраняет
веса лучшей по обобщению модели.

### 1.41 Почему transfer learning важен для малых датасетов?
Позволяет достигать высокой точности при меньших данных и вычислениях —
«демократизирует» продвинутый ML для небольших/узкоспециализированных задач.

### 1.42 Что такое feature drift и concept drift?
**Feature drift** — изменение распределения предикторов. **Concept drift** —
изменение отображения «вход → таргет». Оба со временем ухудшают модель — нужен
постоянный мониторинг и переобучение.

## 2. Подготовка данных и feature engineering

### 2.1 Что такое масштабирование признаков и зачем оно?
Приводит диапазоны признаков к сопоставимому виду — критично для kNN и SVM.
Методы: стандартизация (z-score), Min-Max.

```python
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
```

### 2.2 Объясните One-Hot Encoding.
Превращает категориальные переменные в бинарные векторы: каждая категория — новый
столбец со значениями 0/1.

```python
import pandas as pd
df = pd.DataFrame({"color": ["red", "blue", "green"]})
one_hot = pd.get_dummies(df["color"])
print(one_hot)
```

### 2.3 Что такое нормализация данных?
Приведение признаков к нулевому среднему и единичной дисперсии либо к
фиксированному диапазону (например, 0–1).

```python
from sklearn.preprocessing import MinMaxScaler
scaler = MinMaxScaler()
X_norm = scaler.fit_transform(X)
```

### 2.4 Как обрабатывать пропущенные значения?
Удаление строк; импутация средним/медианой/модой; forward/backward fill.

```python
import pandas as pd
df = df.fillna(df.mean())
```

### 2.5 Что такое feature engineering?
Создание новых или модификация существующих признаков из сырых данных для роста
качества модели.

### 2.6 Примеры feature engineering.
Масштабирование, лог-преобразования, кодирование категорий, извлечение
даты/времени, взаимодействия (произведения/суммы), полиномиальные признаки.

### 2.7 Что такое label encoding?
Превращение категориальных меток в числовые коды.

```python
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
y_encoded = le.fit_transform(y)
```

### 2.8 Что такое DBSCAN?
Плотностный алгоритм кластеризации: группирует близко расположенные точки, а
одиночные в разреженных областях помечает как выбросы.

### 2.9 Что такое batch normalization?
Нормализует входы слоя для каждого мини-батча при обучении — ускоряет и
стабилизирует.

```python
from keras.layers import BatchNormalization
model.add(BatchNormalization())
```

### 2.10 Что такое аугментация данных?
Создание новых обучающих примеров модификацией существующих (поворот, отражение
изображений) — повышает устойчивость и обобщение.

### 2.11 Что такое выброс (outlier)?
Точка, значительно отличающаяся от остальных; может искажать статистику и
качество модели.

### 2.12 Что такое data pipeline?
Последовательность шагов обработки данных (очистка, feature engineering,
моделирование, деплой) для воспроизводимости и автоматизации.

### 2.13 Что такое версионирование данных и зачем оно?
Отслеживание версий датасетов в экспериментах — воспроизводимость и аудит
результатов.

### 2.14 Что такое feature hashing?
Хеш-функция превращает категориальные переменные в векторы фиксированной длины;
часто в NLP.

### 2.15 Что такое утечка в кросс-валидации и как избежать?
Утечка данных — информация извне текущего обучающего фолда «просачивается» в
него, завышая оценки (например, масштабирование/отбор до сплита). Избегать:
трансформации только внутри CV-цикла или через `Pipeline`; никогда не подглядывать
в тест при препроцессинге.

### 2.16 Как обрабатывать категориальные признаки в деревьях и линейных моделях?
Линейные — требуют чисел (label/one-hot encoding). Деревья — могут работать с
label-кодированными категориями нативно (сплиты по дискретным значениям, порядок
не «учится»). Современные (CatBoost, LightGBM) обрабатывают категории без явного
кодирования.

### 2.17 Что такое позиционные кодировки в трансформерах?
Т.к. у трансформеров нет встроенного понятия порядка (в отличие от RNN),
позиционные кодировки добавляют информацию о позиции токенов — синусоидальные или
обучаемые векторы, прибавляемые к эмбеддингам.

### 2.18 Что такое CatBoost и как он работает с категориями?
Библиотека градиентного бустинга, нативно обрабатывающая категориальные
переменные без явного кодирования — через перестановочные статистики при
обучении.

### 2.19 Что такое байесовские нейросети и их преимущество?
Добавляют оценку неопределённости к весам и предсказаниям — калиброванные
доверительные интервалы, детекция выбросов, устойчивые решения; полезны в
медицине и финансах.

### 2.20 Что такое трюк Gumbel-softmax?
Позволяет дифференцируемо сэмплировать из категориального распределения — важно
для обучения сетей с дискретным выбором (neural architecture search, NLP).

### 2.21 Что такое робастная регрессия?
Методы регрессии, менее чувствительные к выбросам, чем OLS: RANSAC, регрессия
Хьюбера, оценка Тейла-Сена.

### 2.22 Роль важности признаков (feature importance) в проектах?
Показывает, какие признаки сильнее влияют на предсказания. Помогает при сборе
данных, feature engineering, доверии к модели; используется для интерпретации,
отладки, комплаенса, научных выводов.

## 3. Оценка, валидация и эксперименты

### 3.1 Как оценивать модель классификации?
Метрики: Accuracy, Precision, Recall, F1, ROC-AUC; матрица ошибок для деталей.

```python
from sklearn.metrics import classification_report, confusion_matrix
y_pred = clf.predict(X_test)
print(classification_report(y_test, y_pred))
print(confusion_matrix(y_test, y_pred))
```

### 3.2 Объясните кросс-валидацию.
Данные делятся на фолды; каждый по очереди служит валидацией, остальные —
обучением. Чаще всего — k-fold.

```python
from sklearn.model_selection import cross_val_score
scores = cross_val_score(clf, X, y, cv=5)
print(scores)
```

### 3.3 Что такое тюнинг гиперпараметров?
Поиск лучшей комбинации настроек модели (глубина дерева, число соседей) для
максимума качества.

```python
from sklearn.model_selection import GridSearchCV
params = {"max_depth": [3, 5, 7]}
grid = GridSearchCV(DecisionTreeClassifier(), params, cv=3)
grid.fit(X, y)
print(grid.best_params_)
```

### 3.4 Что такое матрица ошибок?
Сводка качества классификатора: количества TP, FP, TN, FN.

```python
from sklearn.metrics import confusion_matrix
cm = confusion_matrix(y_test, y_pred)
print(cm)
```

![Матрица ошибок 2×2 с ячейками TP, FP, FN, TN и формулами precision, recall, F1](/kb-img/confusion-matrix.svg)

### 3.5 Зачем нужна ROC-кривая?
График качества бинарного классификатора при изменении порога дискриминации.

```python
from sklearn.metrics import roc_curve, auc
fpr, tpr, thresholds = roc_curve(y_test, y_pred_prob)
print(auc(fpr, tpr))
```

![ROC-кривая с закрашенной площадью AUC и диагональю случайного классификатора](/kb-img/roc-curve.svg)

### 3.6 Что такое precision и recall?
**Precision** — доля истинно положительных среди всех предсказанных
положительными. **Recall** — доля истинно положительных среди всех фактических
положительных.

### 3.7 Что такое деплой модели?
Интеграция обученной модели в продакшн, где она делает предсказания в реальном
времени на новых данных.

### 3.8 Что такое ансамблевое обучение?
Комбинация нескольких моделей (часто слабых) для роста качества, точности и
устойчивости.

### 3.9 Объясните градиентный бустинг.
Модели строятся последовательно; каждая новая обучается на остатках (ошибках)
предыдущей.

```python
from sklearn.ensemble import GradientBoostingClassifier
gb = GradientBoostingClassifier()
gb.fit(X_train, y_train)
```

### 3.10 Термины матрицы ошибок: TP, FP, TN, FN?
TP — истинно положительный, FP — ложноположительный, TN — истинно
отрицательный, FN — ложноотрицательный.

### 3.11 Что такое F1-мера?
Гармоническое среднее precision и recall — баланс обеих в одной метрике.

### 3.12 Что такое свёрточные сети (CNN)?
Сети для данных с решётчатой структурой (изображения); свёрточные слои
автоматически извлекают признаки.

### 3.13 Для чего используется матрица ошибок?
Для наглядной оценки классификатора: верные и ошибочные предсказания по классам.

### 3.14 Что такое silhouette score?
Оценивает, насколько объект похож на свой кластер против других; от −1 до 1
(больше — лучше).

### 3.15 Что такое ROC-AUC?
Площадь под ROC-кривой; мера способности классификатора различать классы (больше
— лучше).

### 3.16 Что такое компромисс precision-recall?
Баланс между precision (меньше FP) и recall (меньше FN); часто нельзя
максимизировать оба.

### 3.17 Что такое pipeline в scikit-learn?
Связывает шаги препроцессинга и модель в единый композитный объект.

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

pipe = Pipeline([("scaler", StandardScaler()), ("clf", LogisticRegression())])
pipe.fit(X_train, y_train)
```

### 3.18 Что такое архитектура Transformer?
Модель на self-attention, обрабатывающая последовательности параллельно; очень
эффективна для языка (GPT, BERT).

### 3.19 Что такое обучение с подкреплением?
Агент выполняет действия в среде, максимизируя сигнал награды во времени.

### 3.20 Что такое марковский процесс принятия решений (MDP)?
Каркас моделирования решений: состояния, действия, награды, вероятности переходов;
основа RL.

### 3.21 Что такое утечка данных (data leakage)?
Использование информации извне обучающего набора при построении модели → чрезмерно
оптимистичные оценки.

### 3.22 Что такое оптимизация гиперпараметров?
Систематический поиск лучших гиперпараметров: Grid Search, Random Search,
байесовская оптимизация.

### 3.23 Что такое precision-recall кривая?
График компромисса precision/recall при разных порогах вероятности.

### 3.24 Что такое калибровка модели?
Подстройка предсказанных вероятностей к истинным частотам (Platt scaling,
изотоническая регрессия).

### 3.25 Что такое пространство поиска гиперпараметров?
Диапазоны и значения всех настраиваемых параметров при оптимизации.

### 3.26 Что такое стратифицированная k-fold и когда её применять?
Сохраняет распределение классов во всех фолдах. Применять при несбалансированной
классификации — чтобы классы были равно представлены в каждом сплите.

```python
from sklearn.model_selection import StratifiedKFold
skf = StratifiedKFold(n_splits=5)
for train_idx, val_idx in skf.split(X, y):
    X_train, X_val = X[train_idx], X[val_idx]
    y_train, y_val = y[train_idx], y[val_idx]
```

### 3.27 ROC-кривая и AUC — практическое значение.
**ROC** — TPR (чувствительность) против FPR при разных порогах. **AUC** —
одно число (макс. 1); выше = лучше различение классов. Полезно при дисбалансе и
когда важен ранжирующий порядок, а не только accuracy.

```python
from sklearn.metrics import roc_curve, roc_auc_score
y_prob = clf.predict_proba(X_test)[:, 1]
fpr, tpr, thresholds = roc_curve(y_test, y_prob)
auc = roc_auc_score(y_test, y_prob)
```

### 3.28 Разница между recall и specificity?
**Recall (TPR):** $\frac{TP}{TP+FN}$ — доля пойманных фактических положительных.
**Specificity (TNR):** $\frac{TN}{TN+FP}$ — доля верно определённых
отрицательных. Recall важен, когда пропуск положительного дорог (диагностика);
specificity — когда дороги ложные срабатывания (спам-фильтры).

### 3.29 Что такое квантизация при деплое?
Снижение точности чисел (весов/активаций), например float32 → int8 — эффективно
для edge/мобильных устройств при небольшой потере точности.

### 3.30 Что такое out-of-bag (OOB) ошибка в случайном лесе?
Оценка обобщения: для каждого дерева используются образцы, не попавшие в его
бутстрап («out-of-bag»). Лес объединяет OOB-предсказания как встроенную
кросс-валидацию — отдельная валидация не нужна.

### 3.31 Что такое пайплайнинг в MLOps?
Автоматизация и связывание всех стадий ML (сбор, препроцессинг, обучение, тест,
деплой) для воспроизводимости и быстрых итераций (Kubeflow, MLflow, Airflow).

### 3.32 Что такое шардирование данных (data sharding)?
Деление больших датасетов на управляемые части (шарды) на разных машинах —
масштабируемость и производительность распределённого ML.

### 3.33 Что такое эволюционные вычисления в ML?
Семейство оптимизационных алгоритмов, вдохновлённых эволюцией (генетические
алгоритмы). Оптимизируют модели, гиперпараметры, архитектуры сетей.

### 3.34 Что такое многокритериальная оптимизация?
Оптимизация по нескольким конфликтующим метрикам (точность и размер модели).
Решения оцениваются по Парето-оптимальности. Пример: точность vs задержка на
мобильных.

### 3.35 Что такое transferability в состязательном ML?
Состязательные примеры для одной модели часто обманывают и другие (даже с иной
архитектурой). Вывод: устойчивость проверять и «white-box», и «black-box»
атаками.

### 3.36 Тюнинг гиперпараметров через байесовскую оптимизацию?
Метрика моделируется как вероятностная функция гиперпараметров (например,
гауссовский процесс); новые точки выбираются по неопределённости и ожидаемому
улучшению. Плюс: меньше запусков, быстрее сходимость.

### 3.37 Почему ансамбли часто используют на Kaggle?
Ансамбли объединяют сильные стороны и компенсируют слабые — точность и обобщение
выше любой одиночной модели. Победные решения часто усредняют/стекают десятки
моделей.

### 3.38 Что такое дисбаланс классов и его влияние?
Большинство примеров в одном классе, мало в другом (фрод, редкие болезни). Модель
«жульничает», предсказывая мажоритарный класс; детекция миноритарного страдает,
accuracy вводит в заблуждение.

### 3.39 Как бороться с дисбалансом классов?
Ребалансировка (oversample миноритарного — SMOTE; undersample мажоритарного);
веса классов; сдвиг порога решения; оценка по recall/precision/F1/ROC-AUC, а не по
accuracy.

### 3.40 Что такое калибровка модели и почему важна?
Предсказанные вероятности отражают реальные частоты (в калиброванной модели «риск
70%» = событие происходит в 70% случаев). Критично в риск-чувствительных задачах;
достигается Platt scaling, изотонической регрессией.

### 3.41 Что такое бутстрэп и зачем он?
Генерация множества ресэмплированных (с возвращением) наборов для оценки
изменчивости, доверительных интервалов, bagging/ансамблей. Даёт понимание
стабильности модели; основа статистического вывода.

## 4. Классические алгоритмы обучения с учителем

### 4.1 Разница между классификацией и регрессией.

| Признак | Классификация | Регрессия |
|---|---|---|
| Тип выхода | Дискретные категории | Непрерывные значения |
| Пример | Спам / не спам | Прогноз цены дома |
| Алгоритмы | Логистическая регрессия, SVM | Линейная регрессия, SVR |

### 4.2 Как работает k ближайших соседей (kNN)?
Непараметрический алгоритм: классифицирует точку по «k» ближайшим размеченным
соседям; для регрессии усредняет их значения.

```python
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=3)
knn.fit(X_train, y_train)
predictions = knn.predict(X_test)
```

### 4.3 Что такое перцептрон?
Простейшая нейросеть: один слой с одним нейроном; бинарная линейная
классификация.

```python
from sklearn.linear_model import Perceptron
p = Perceptron()
p.fit(X_train, y_train)
```

### 4.4 Что такое кросс-энтропийная потеря?
Мера качества классификатора с вероятностным выходом (0–1); растёт при отклонении
предсказанной вероятности от истинной метки.

### 4.5 Что такое деревья решений и как работают?
Классифицируют данные, разбивая узлы по значениям признаков; критерии сплита —
Джини или энтропия; до чистоты или максимальной глубины.

### 4.6 Что такое энтропия в деревьях?
Мера нечистоты/беспорядка в узле; используется для выбора оптимальных сплитов (как
в ID3).

### 4.7 Разница параметрических и непараметрических моделей?

| Параметрические | Непараметрические |
|---|---|
| Предполагают распределение данных | Меньше допущений |
| Меньше параметров | Гибче, часто больше параметров |
| Пример: линейная регрессия | Пример: kNN, деревья |

### 4.8 Что такое узел смещения (bias node) в нейросетях?
Позволяет сдвигать кривую активации, улучшая обучение — аналог свободного члена в
регрессии.

### 4.9 Что такое softmax?
Превращает вектор «сырых» оценок (логитов) в вероятности, сумма которых равна 1;
обычно в выходном слое многоклассовой классификации.

```python
import numpy as np
def softmax(x):
    e_x = np.exp(x - np.max(x))
    return e_x / e_x.sum(axis=0)
```

### 4.10 Что такое многоклассовая классификация?
Выход может относиться более чем к двум категориям (например, типы фруктов).

### 4.11 Что такое многометочная (multi-label) классификация?
Каждому входу можно присвоить несколько меток (теги объектов на изображении).

### 4.12 Что такое прогнозирование временных рядов?
Предсказание будущих значений по историческим данным с временным порядком
(ARIMA, LSTM).

### 4.13 Что такое ARIMA?
Auto-Regressive Integrated Moving Average — популярная линейная модель прогноза
временных рядов.

### 4.14 Разница жёсткой и мягкой классификации?

| Жёсткая | Мягкая |
|---|---|
| Только метки классов | Вероятности каждого класса |

### 4.15 Что такое multi-output регрессия?
Одновременное предсказание нескольких непрерывных значений.

### 4.16 Что такое квантильная регрессия?
Предсказывает условные квантили (а не среднее) — полезно для медианы/диапазонов.

### 4.17 Что такое обучение метрики расстояния (distance metric learning)?
Обучение подходящей функции расстояния (вместо евклидовой) для кластеризации,
поиска.

### 4.18 Что такое стекинг (stacking) ансамблей?
Комбинирует несколько базовых моделей, обучая мета-модель на их выходах.
Как: 1) поделить обучающие данные; 2) обучить базовые модели на первой части;
3) получить их out-of-fold предсказания на второй; 4) обучить мета-модель на этих
предсказаниях; 5) на тесте базовые модели дают выходы → мета-модель даёт финал.

```python
from sklearn.ensemble import StackingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC

estimators = [
    ("tree", DecisionTreeClassifier()),
    ("svc", SVC(probability=True)),
]
clf = StackingClassifier(estimators=estimators,
                         final_estimator=LogisticRegression())
clf.fit(X_train, y_train)
```

### 4.19 Что такое LIME?
Local Interpretable Model-agnostic Explanations — объясняет предсказание, локально
возмущая вход и подгоняя простую интерпретируемую модель к результатам.

### 4.20 Что такое свободный член (intercept) в регрессии?
Константа, позволяющая функции сдвигаться вверх/вниз для лучшего соответствия
данным. Без него предсказания «проходят через начало координат» и могут
искажаться.

## 5. Ансамбли и бустинг

### 5.1 Разница bagging и boosting.

| Bagging | Boosting |
|---|---|
| Модели обучаются параллельно | Последовательно |
| Снижает разброс | Снижает смещение |
| Пример: Random Forest | Пример: AdaBoost, XGBoost |

![Bagging обучает модели параллельно и усредняет; boosting строит модели последовательно, каждая исправляет ошибки предыдущей](/kb-img/bagging-boosting.svg)

### 5.2 Назовите распространённые ансамблевые алгоритмы.
Random Forest, Bagging, Boosting (AdaBoost, Gradient Boosting, XGBoost), Stacking,
Voting Classifier.

### 5.3 Что такое стекинг?
Комбинирует предсказания нескольких базовых моделей (с разными сильными
сторонами) через мета-модель.

### 5.4 Что такое bagging (с примером)?
Обучает несколько моделей на случайных подвыборках с возвращением и усредняет.
Пример: Random Forest.

### 5.5 Что такое boosting (с примером)?
Обучает модели последовательно, каждая исправляет ошибки предыдущей. Пример:
AdaBoost, Gradient Boosting.

### 5.6 Как работать с несбалансированными данными?
Oversample миноритарного (SMOTE), undersample мажоритарного, веса классов,
ансамбли для дисбаланса.

```python
from sklearn.linear_model import LogisticRegression
lr = LogisticRegression(class_weight="balanced")
```

### 5.7 Bagging vs boosting в одну строку.
Bagging усредняет предсказания многих независимых моделей; boosting строит модели
последовательно, каждая исправляет ошибки предыдущих.

## 6. Обучение без учителя и кластеризация

### 6.1 Что такое k-means?
Разбивает данные на «k» кластеров, итеративно приписывая точки к ближайшим
центроидам.

```python
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=3)
labels = kmeans.fit_predict(X)
```

### 6.2 Что такое иерархическая кластеризация?
Строит иерархию кластеров: слиянием (агломеративная) или разбиением (дивизивная).

### 6.3 Что такое поиск аномалий?
Выявление редких объектов/событий, значительно отличающихся от большинства.

### 6.4 Что такое метод локтя (elbow) в кластеризации?
Определение оптимального числа кластеров в k-means: строят внутрикластерную сумму
квадратов и ищут «локоть», где убывание резко замедляется.

### 6.5 Формула силуэтного коэффициента?
Для точки $i$:

$$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$

где $a(i)$ — среднее внутрикластерное расстояние, $b(i)$ — расстояние до
ближайшего кластера.

## 7. Снижение размерности

### 7.1 Что такое метод главных компонент (PCA)?
Преобразует данные в меньшее число некоррелированных переменных (главных
компонент), сохраняя максимум дисперсии.

![PCA: снижение размерности через главные компоненты](/kb-img/pca.svg)

```python
from sklearn.decomposition import PCA
pca = PCA(n_components=2)
X_reduced = pca.fit_transform(X)
```

### 7.2 Объясните снижение размерности.
Уменьшение числа входных переменных (PCA, t-SNE) для ускорения обучения,
визуализации и борьбы с проклятием размерности.

### 7.3 Что такое t-SNE?
t-distributed Stochastic Neighbor Embedding — метод снижения размерности в
основном для визуализации многомерных данных.

### 7.4 Что такое сингулярное разложение (SVD)?
Факторизация матрицы в произведение трёх матриц. Применение: снижение размерности
(LSA в NLP), рекомендательные системы, сжатие изображений.

## 8. Deep Learning: базовые концепции

### 8.1 Объясните batch gradient descent.
Вычисляет градиент функции стоимости по **всему** обучающему датасету и обновляет
параметры на каждой итерации.

### 8.2 Что контролирует learning rate?
Размер шага при градиентном спуске. Слишком большой → расходимость; слишком малый
→ медленная сходимость.

### 8.3 Что такое рекуррентные сети (RNN)?
Сети для последовательных данных (временные ряды, текст), где выходы зависят от
предыдущих вычислений (есть «память»).

### 8.4 Что такое функция активации?
Вводит нелинейность, позволяя сети учить сложные зависимости. Примеры: ReLU,
sigmoid, tanh.

### 8.5 Что такое ReLU?
Rectified Linear Unit: ноль для отрицательного входа и сам вход для
положительного: $f(x) = \max(0, x)$.

### 8.6 Что такое инициализация Xavier/Glorot?
Инициализация весов сети для предотвращения затухания/взрыва градиентов,
сохраняющая дисперсию между слоями.

### 8.7 Что такое затухание/взрыв градиентов?
Когда градиенты становятся крайне малыми (затухание) или большими (взрыв),
затрудняя обучение, особенно в глубоких сетях.

### 8.8 Что такое эпоха (epoch)?
Один полный проход по всему обучающему датасету.

### 8.9 Что такое mini-batch gradient descent?
Обновляет параметры по небольшой случайной подвыборке (мини-батчу) на каждой
итерации — баланс скорости и сходимости.

### 8.10 Главная роль функции потерь?
Количественно измеряет, насколько предсказания соответствуют целям; направляет
обновление весов.

### 8.11 Что такое генератор в deep learning?
Python-функция/объект, выдающий батчи данных «на лету» — эффективная подача
данных при обучении.

### 8.12 Что такое генеративно-состязательные сети (GAN)?
Генератор и дискриминатор соревнуются: генератор создаёт фейковые данные,
дискриминатор отличает настоящие от фейковых.

### 8.13 Что такое LSTM?
Long Short-Term Memory — архитектура RNN для захвата долгосрочных зависимостей и
смягчения затухания градиентов.

### 8.14 Что такое планировщик learning rate?
Инструмент, меняющий learning rate при обучении (часто снижая на плато) для лучшей
сходимости.

### 8.15 Что такое механизм внимания (attention)?
Позволяет сети фокусироваться на важных частях входа (например, токенах в NLP),
улучшая качество на последовательностях.

### 8.16 Что такое проблема взрыва градиентов?
Градиенты растут неконтролируемо → нестабильные обновления, особенно в глубоких
и рекуррентных сетях.

### 8.17 Что такое кастомная функция потерь?
Пользовательская метрика для обучения, реализуемая через подклассы/функции
(Keras, PyTorch).

### 8.18 Из-за чего в основном затухают градиенты?
Активации типа sigmoid/tanh «сжимают» градиенты, из-за чего они уменьшаются в
глубоких сетях.

### 8.19 Что такое отжиг learning rate (annealing)?
Постепенное снижение learning rate при обучении — плавная сходимость и выход из
локальных минимумов. Стратегии: step decay, exponential decay, reduce-on-plateau.

```python
from keras.callbacks import ReduceLROnPlateau
ReduceLROnPlateau(monitor="val_loss", factor=0.1, patience=5)
```

### 8.20 Bag-of-words vs эмбеддинги для NLP.
**BoW** — документ как вектор частот/индикаторов слов, без порядка/контекста.
**Эмбеддинги** — плотные векторы в непрерывном пространстве, сохраняющие семантику
(king − man + woman = queen). Эмбеддинги (Word2Vec, GloVe, BERT) предпочтительнее
для нейросетей.

### 8.21 Что такое графовая нейросеть (GNN)?
Сети, работающие напрямую с графами: учат представления узлов/рёбер/графов,
агрегируя информацию от соседей. Применения: соцсети, свойства молекул, фрод.

### 8.22 Что такое равновесие Нэша в ML?
В мультиагентных сценариях (теория игр) — ситуация, где ни один агент не выигрывает,
меняя свою стратегию, если другие не меняют. Применения: мультиагентный RL,
динамика обучения GAN.

### 8.23 Что такое иерархическое обучение с подкреплением?
Организует обучение в иерархию: высокоуровневые «менеджеры» задают подцели,
низкоуровневые политики их выполняют. Плюс: эффективность в сложных
долгогоризонтных задачах.

## 9. NLP и трансформеры

### 9.1 Что такое эмбеддинги слов?
Плотные векторные представления слов (Word2Vec, GloVe), кодирующие семантику.

### 9.2 Что такое word2vec?
Алгоритм обучения эмбеддингов: отображает слова в векторное пространство так, что
похожие слова имеют близкие векторы.

### 9.3 Разница Bag of Words и TF-IDF.

| Bag of Words | TF-IDF |
|---|---|
| Считает вхождения слов | Взвешивает по частоте и различимости |
| Игнорирует важность | Отражает релевантность слова в документе/контексте |

### 9.4 Что такое BERT?
Bidirectional Encoder Representations from Transformers — предобученная NLP-модель
на трансформере для понимания контекста языка.

![Архитектура Transformer: encoder-only (BERT) vs decoder-only (GPT)](/kb-img/transformer.svg)

### 9.5 Что такое negative sampling?
Техника обучения эмбеддингов/рекомендаций: вводят фейковые (негативные) примеры
для контраста с позитивными.

### 9.6 Что такое multi-head attention и почему важно?
Позволяет модели одновременно «смотреть» на информацию из разных подпространств
представлений на разных позициях. Каждая «голова» учит независимые оценки
внимания, затем выходы конкатенируются. Важно: одновременное изучение разных
связей (синтаксис, семантика); усиление в переводе, суммаризации, CV.

### 9.7 Что такое маскирование внимания (attention masking)?
Используется в трансформерах, чтобы не «смотреть» на определённые позиции
(padding-токены или будущие токены в авторегрессии) — модель не «жульничает»,
заглядывая вперёд.

## 10. Обучение с подкреплением

### 10.1 Что такое Q-learning?
Алгоритм RL, обучающий оптимальные действия через Q-функцию для каждой пары
«состояние-действие».

### 10.2 Что такое reward shaping?
Модификация функции награды для более частой/информативной обратной связи —
ускоряет обучение, но требует осторожности во избежание нежелательного поведения.

### 10.3 Что такое Monte Carlo Tree Search?
Стратегия принятия решений (особенно в играх): сочетает случайность (симуляции
Монте-Карло) и поиск по дереву. Знаменитое применение — AlphaGo.

### 10.4 Что такое bandit learning?
Задачи многорукого бандита: баланс «исследования» (новые действия) и
«эксплуатации» (лучшее известное) для максимизации награды. Применения: онлайн-
реклама, A/B-тесты, рекомендации.

### 10.5 Разница exploration и exploitation в RL?
**Exploration** — пробовать новые действия для поиска наград. **Exploitation** —
использовать известные высокодоходные действия. Баланс не даёт агенту застрять в
субоптимальном поведении.

### 11.1 Что такое сериализация модели и зачем она?
Сохранение обученной модели (pickle/joblib) для повторной загрузки без
переобучения.

```python
import joblib
joblib.dump(model, "model.pkl")   # сохранить
model = joblib.load("model.pkl")  # загрузить
```

### 11.2 Назовите инструменты деплоя модели.
Flask, FastAPI, Docker, TensorFlow Serving, AWS Lambda, Heroku, Google Cloud ML,
Azure ML.

### 11.3 Почему интерпретируемость всё важнее?
ML принимает значимые решения (кредиты, диагностика, найм) — стейкхолдеры должны
понимать, доверять и аудировать предсказания. Это ядро безопасности ИИ и
ответственного деплоя.

## 12. Объяснимость, устойчивость и приватность

### 12.1 Что такое интерпретируемость модели и почему важна?
Насколько легко человек понимает логику решений модели; важно для доверия,
отладки, комплаенса.

### 12.2 Перечислите техники интерпретируемости.
Feature importance, SHAP-значения, LIME, Partial Dependence Plots.

### 12.3 Что такое объяснимый ИИ (XAI)?
Область, делающая предсказания ML понятными людям.

### 12.4 Что такое важность признаков?
Мера вклада каждой входной переменной в предсказание; часто дают деревья.

### 12.5 Что такое SHAP и чем отличается от LIME?
**SHAP** (SHapley Additive exPlanations) считает вклады признаков для отдельных
предсказаний на основе кооперативной теории игр — согласованные, теоретически
обоснованные объяснения. **LIME** локален и эвристичен; SHAP имеет теоретические
гарантии.

### 12.6 Explainability vs interpretability?
**Интерпретируемость** — насколько человек понимает решения модели (простые
модели, feature importance). **Объяснимость** — инструменты, делающие «чёрные
ящики» понятными (SHAP, LIME, контрфактические объяснения).

### 12.7 Что такое состязательное обучение (adversarial training)?
Метод повышения устойчивости к состязательным атакам: в обучение добавляют
состязательные примеры (FGSM, PGD), и модель учится верно классифицировать и
чистые, и возмущённые примеры. Применения: автономный транспорт, биометрия.

### 12.8 Что такое федеративное обучение?
Распределённый подход: модели обучаются на многих устройствах (смартфоны) на
локальных данных — данные не покидают устройство. Плюсы: приватность, комплаенс,
меньше централизованного хранения.

### 12.9 Что такое privacy-preserving ML?
Методы обучения/деплоя без раскрытия чувствительных данных: дифференциальная
приватность, гомоморфное шифрование, безопасные многосторонние вычисления.

### 12.10 Что такое дифференциальная приватность?
Математическая гарантия, что включение/исключение одной точки минимально влияет на
выход модели — через добавление калиброванного шума. Используют Apple, Google, Бюро
переписи США.

### 12.11 Что такое SHAP-значения и как помогают объяснимости?
Количественно оценивают аддитивный вклад каждого признака в предсказание (теория
игр). Сильные стороны: локальная и глобальная интерпретируемость, теоретическая
согласованность, применимость к многим типам моделей.

## 13. Графы и продвинутые темы

### 13.1 Объясните дистилляцию знаний (knowledge distillation).
Перенос знаний от большой сложной модели («учитель») к меньшей и быстрой
(«ученик»), обучая ученика имитировать выходы/поведение учителя — для лёгкого
инференса.

### 13.2 Что такое мета-обучение («learning to learn»)?
Алгоритмы, учащиеся быстро адаптироваться к новым задачам с минимумом данных,
находя обобщающие инициализации/стратегии (например, MAML).

### 13.3 Что такое curriculum learning?
Стратегия обучения: модели сначала показывают простые примеры, затем сложность
постепенно растёт. Имитирует обучение человека; ускоряет сходимость и улучшает
обобщение.

### 13.4 Что такое эмбеддинг графа знаний (knowledge graph embedding)?
Представление сущностей и связей графа знаний как низкоразмерных векторов — для
использования в ML (question answering, link prediction, рекомендации).

### 13.5 Что такое node2vec?
Масштабируемый алгоритм генерации эмбеддингов узлов больших сетей через смещённые
случайные блуждания (захватывает и общность, и структурную эквивалентность).

## 14. Разное

### 14.1 Что такое нечистота Джини (Gini impurity)?
Вероятность неверной классификации случайно выбранного элемента при случайном
назначении согласно распределению классов в узле.

### 14.2 Что такое дисбаланс классов?
Когда одни классы представлены гораздо чаще других — затрудняет оценку и
предсказание.

### 14.3 (Отсутствует в исходном PDF)
Нумерация в оригинале перескакивает с Q50 на Q52.

### 14.4 Что такое fine-tuning?
Адаптация предобученной модели на подмножестве новых данных — эффективное обучение
под конкретную задачу.

### 14.5 Что такое zero-shot learning?
Модель верно предсказывает на классах, не виденных при обучении — через
семантические связи.

### 14.6 Что такое SMOTE?
Synthetic Minority Over-sampling Technique — генерирует синтетические примеры
миноритарного класса против дисбаланса.

```python
from imblearn.over_sampling import SMOTE
sm = SMOTE()
X_res, y_res = sm.fit_resample(X, y)
```

### 14.7 Что такое ранняя и поздняя фузия в мультимодальном обучении?
**Ранняя фузия** объединяет сырые признаки разных модальностей; **поздняя** —
предсказания или обученные представления.

### 14.8 Что такое остаточные связи (residual connections) и почему работают?
Skip-связи прибавляют вход слоя к его выходу (как в ResNet):

$$\text{output} = F(x) + x$$

Позволяют градиентам легче течь через глубокие сети, упрощают оптимизацию и делают
возможными очень глубокие архитектуры.

### 14.9 Что такое проклятие размерности?
С ростом числа признаков данные становятся разрежёнными (больше комбинаций для
покрытия), а меры расстояния теряют смысл — качество модели падает.

### 14.10 Что такое непрерывное обучение (continual learning)?
Способность модели учить новые задачи последовательно, сохраняя знания о прошлых
(избегая «катастрофического забывания»). Важно для систем, адаптирующихся со
временем (ассистенты, роботы) без переобучения с нуля.
