## Распределения

### Дискретные

- **Биномиальное** — $x$ успехов в $n$ испытаниях, каждое с вероятностью $p$:
  $$\binom{n}{x}p^x q^{\,n-x}, \quad \mu = np, \quad \sigma^2 = npq$$
  При $n = 1$ — это **распределение Бернулли**.
- **Геометрическое** — первый успех с вероятностью $p$ на $n$-м испытании:
  $$q^{\,n-1}p, \quad \mu = \tfrac{1}{p}, \quad \sigma^2 = \tfrac{1-p}{p^2}$$
- **Отрицательное биномиальное** — число неудач до $r$ успехов.
- **Гипергеометрическое** — $x$ успехов в $n$ выборах без возвращения из популяции размера $N$ с $X$ объектами нужного признака:
  $$\frac{\binom{X}{x}\binom{N-X}{\,n-x}}{\binom{N}{n}}, \quad \mu = \tfrac{nX}{N}$$
- **Пуассона** — число успехов $x$ за фиксированный интервал при средней интенсивности $\lambda$:
  $$\frac{\lambda^x e^{-\lambda}}{x!}, \quad \mu = \sigma^2 = \lambda$$

### Непрерывные

- **Равномерное** — все значения между $a$ и $b$ равновероятны:
  $$\frac{1}{b-a}, \quad \mu = \tfrac{a+b}{2}, \quad \sigma^2 = \tfrac{(b-a)^2}{12}$$
- **Нормальное (Гаусса)** $N(\mu, \sigma)$, стандартное нормальное $Z \sim N(0, 1)$.
  - **ЦПТ (центральная предельная теорема)** — среднее выборки i.i.d.-данных стремится к нормальному распределению.
  - **Правило трёх сигм** — 68% / 95% / 99.7% значений лежат в пределах одного, двух и трёх стандартных отклонений от среднего.
  - **Нормальная аппроксимация** — дискретные распределения (биномиальное, Пуассона) можно приближать через z-оценки, когда $np$, $nq$ и $\lambda$ больше 10.
- **Экспоненциальное** — «без памяти», время между независимыми событиями при интенсивности $\lambda$:
  $$\lambda e^{-\lambda x}, \quad \mu = \tfrac{1}{\lambda}$$
- **Гамма** — время до наступления $n$ независимых событий при интенсивности $\lambda$.

## Базовые концепции

**Ошибка предсказания** = $\text{Смещение}^2$ + Разброс + Неустранимый шум.

- **Смещение (bias)** — неверные допущения при обучении → модель не улавливает закономерности → **недообучение (underfit)**.
- **Разброс (variance)** — чувствительность к колебаниям обучающих данных → модель не обобщается → **переобучение (overfit)**.

**Компромисс смещение-разброс** минимизирует оба источника ошибки, например через:

- Кросс-валидацию (обобщение на невиданные данные).
- Снижение размерности и отбор признаков.

Во всех случаях: при уменьшении разброса растёт смещение.

Модели делятся на два типа:

- **Параметрические** — фиксированное число параметров независимо от размера выборки.
- **Непараметрические** — гибкое число параметров, без жёстких допущений о данных.

**Кросс-валидация** — оценивает тестовую ошибку на подмножестве обучающих данных и подбирает параметры, максимизирующие среднее качество.

- **k-fold** — делим данные на $k$ групп, одну используем для валидации.
- **leave-p-out** — $p$ образцов на валидацию, остальные — на обучение.

## Оценка моделей

### Регрессия

$$\text{MSE} = \tfrac{1}{n}\sum (y_i - \hat{y})^2 \qquad \text{SSE} = \sum (y_i - \hat{y})^2 \qquad \text{SST} = \sum (y_i - \bar{y})^2$$

$$R^2 = 1 - \frac{\text{SSE}}{\text{SST}} \quad (\text{доля объяснённой дисперсии } y)$$

Отрицательный $R^2$ означает, что модель хуже, чем просто предсказание среднего. $R^2$ некорректен для нелинейных моделей.

$$R^2_{adj} = 1 - (1 - R^2)\frac{N-1}{N-p-1}$$

Скорректированный $R^2$ меняется только когда предикторы влияют на $R^2$ сильнее случайного.

### Классификация

| | Предсказано «Да» | Предсказано «Нет» |
|---|---|---|
| **Факт «Да»** | True Positive $(1-\beta)$ | False Negative $(\beta)$ |
| **Факт «Нет»** | False Positive $(\alpha)$ | True Negative $(1-\alpha)$ |

- **Precision (точность)** $= \frac{TP}{TP+FP}$ — доля верных среди предсказанных положительных.
- **Recall / Sensitivity (полнота)** $= \frac{TP}{TP+FN}$ — доля найденных фактических положительных (TPR).
- **Specificity (специфичность)** $= \frac{TN}{TN+FP}$ — доля найденных фактических отрицательных (1 − FPR).
- **F1** $= 2\cdot\frac{precision \cdot recall}{precision + recall}$ — полезна при несбалансированных классах.

**ROC-кривая** — строит TPR против FPR для каждого порога $\alpha$. **AUC** измеряет, насколько модель отличает положительные от отрицательных (идеал = 1, база = 0.5).

**Precision-Recall кривая** — фокус на верном предсказании миноритарного класса; полезна при дисбалансе.

## Линейная регрессия

Моделирует линейную связь между непрерывным откликом и объясняющими переменными.

**Метод наименьших квадратов (OLS)** — находим $\hat\beta$ для $\hat{y} = \hat\beta_0 + \hat\beta X + \varepsilon$, решая
$$\hat\beta = (X^T X)^{-1} X^T Y \quad (\text{минимизирует SSE})$$

**Допущения:**

- Линейная связь и независимость наблюдений.
- **Гомоскедастичность** — постоянная дисперсия ошибок.
- Ошибки некоррелированы и нормально распределены.
- Низкая мультиколлинеарность.

**Фактор инфляции дисперсии (VIF)** — измеряет тяжесть мультиколлинеарности:
$$\text{VIF} = \frac{1}{1 - R_i^2}$$
где $R_i^2$ получают, регрессируя $X_i$ на все прочие переменные (частый порог отсечения — 10).

## Регуляризация

Добавляет штраф $\lambda$ за большие коэффициенты к функции стоимости — уменьшает переобучение. Требует нормализованных данных.

- **Subset (L0):** $\lambda\lVert\hat\beta\rVert_0 = \lambda\cdot(\text{число ненулевых переменных})$.
  - Вычислительно медленно (нужно обучить $2^k$ моделей). Альтернативы — forward/backward stepwise selection.
- **LASSO (L1):** $\lambda\lVert\hat\beta\rVert_1 = \lambda\sum|\hat\beta|$.
  - Зануляет коэффициенты, устойчив к выбросам.
- **Ridge (L2):** $\lambda\lVert\hat\beta\rVert_2 = \lambda\sum(\hat\beta)^2$.
  - Снижает эффект мультиколлинеарности.
- **Elastic Net** — комбинация LASSO и Ridge.

## Логистическая регрессия

Предсказывает вероятность принадлежности $y$ к бинарному классу. Оценивает $\beta$ через **максимум правдоподобия (MLE)**, подгоняя логистическую (сигмоидную) функцию — это эквивалентно минимизации кросс-энтропии. Регуляризацию можно добавить в экспоненту.

$$P(Y = 1) = \frac{1}{1 + e^{-(\beta_0 + \beta x)}}$$

Порог $a$ классифицирует предсказания как 1 или 0.

**Допущения:** линейная связь между $X$ и лог-шансами $Y$; независимость наблюдений; низкая мультиколлинеарность.

**Шансы (odds):** $\text{Odds}(Y=1) = \frac{P(Y=1)}{1 - P(Y=1)}$. Коэффициенты линейно связаны с логарифмом шансов: увеличение $x_1$ на единицу меняет шансы в $e^{\beta_1}$ раз.

## Деревья решений

**CART (Classification and Regression Tree).**

- **Для регрессии** минимизирует SSE, разбивая данные на подобласти и предсказывая среднее в листьях. Параметр сложности $cp$ оставляет только те разбиения, которые снижают потери минимум на $cp$ (малый $cp$ → глубокое дерево).
- **Для классификации** минимизирует суммарную «нечистоту» областей, где $\hat{p}_i$ — вероятность попасть в категорию $i$ (макс. нечистота 0.5):
  - **Джини:** $\text{Gini} = 1 - \sum(\hat{p}_i)^2$
  - **Кросс-энтропия:** $-\sum(\hat{p}_i)\log_2(\hat{p}_i)$

В листе предсказывается самая частая категория. Разбиение устойчиво к мультиколлинеарности и выбросам. Деревья склонны к высокому разбросу — настраивайте через CV.

## Случайный лес

Ансамбль деревьев, голосующих за итоговое предсказание.

- **Bootstrapping** — выборка с возвращением (с дубликатами) до размера обучающей выборки.
- **Bagging** — обучение независимых моделей на разных подмножествах данных → снижает разброс. Каждое дерево видит ~63% данных, поэтому оставшиеся **out-of-bag 37%** оценивают ошибку без CV.

Глубокие деревья могут переобучаться, но добавление деревьев **не** ведёт к переобучению. Смещение модели всегда равно смещению отдельного дерева.

**Важность переменных** — ранжирует признаки по способности снижать ошибку при разбиении, усреднённой по всем деревьям.

## Метод опорных векторов (SVM)

Разделяет два класса, максимизируя **зазор** между гиперплоскостью и ближайшими точками любого класса.

- **Support Vector Classifier** — учитывает выбросы через параметр регуляризации $C > 0$, штрафующий ошибки внутри зазора.
- **Ядровые функции (kernels)** — решают нелинейные задачи, вычисляя схожесть точек $a, b$ и отображая данные в пространство большей размерности:
  - Полиномиальное: $(ab + r)^d$
  - Радиальное (RBF): $e^{-\gamma(a-b)^2}$, где меньший $\gamma$ → более гладкие границы.
- **Hinge Loss:** $\max(0, 1 - y_i(w^T x_i - b))$ — функция стоимости SVM (классы $\pm 1$). Даже верное предсказание внутри зазора даёт потери > 0.

## Многоклассовая классификация

Для 3+ классов $C$ задачу бинаризуют:

- **One vs. Rest** — для каждого класса $c_i$ обучаем классификатор (образцы $c_i$ = 1, остальные = 0); выбираем класс с наибольшей уверенностью.
- **One vs. One** — обучаем $\frac{C(C-1)}{2}$ моделей на каждую пару классов; выбираем класс с наибольшим числом положительных голосов.

## k ближайших соседей (k-NN)

Непараметрический метод: $\hat{y}$ — среднее значение или самый частый класс среди $k$ ближайших точек. Для многомерных данных информация теряется (равноудалённые векторы), поэтому часто применяют снижение размерности до k-NN.

- **Расстояние Минковского:** $\left(\sum |a_i - b_i|^p\right)^{1/p}$
  - $p = 1$ — Манхэттенское $\sum|a_i - b_i|$.
  - $p = 2$ — Евклидово $\sqrt{\sum(a_i - b_i)^2}$.
- **Расстояние Хэмминга** — число различий между векторами, часто для категориальных.

## Кластеризация

Обучение без учителя, непараметрическое: группирует похожие точки по расстоянию.

### k-Means

Случайно размещаем $k$ центроидов на нормализованных данных, приписываем точки к ближайшему центроиду, пересчитываем центроиды как среднее назначенных точек, повторяем до сходимости. Медиана/медоид устойчивее к шуму; **k-modes** — для категориальных данных.

**k-means++** улучшает выбор начальных центров:
1. Первый центр — случайно.
2. Считаем расстояние точек до ближайшего центра.
3. Новый центр — по взвешенной вероятности, пропорциональной расстоянию.
4. Повторяем, пока не выбраны $k$ центров.

Оценка числа кластеров и качества:

- **Silhouette (силуэт)** — насколько точка похожа на свой кластер против других; от 1 (лучше) до −1 (хуже).
- **Индекс Дэвиса-Болдина** — отношение внутрикластерного разброса к межкластерному разделению; меньше — лучше.

### Иерархическая кластеризация

- **Агломеративный подход:** каждая точка — свой кластер → итеративно объединяем самые похожие пары → пока всё не в одном кластере.
- **Дивизивный подход:** все точки в одном кластере, рекурсивно разбиваем.
- **Метрики связи (linkage):** Single (ближайшая пара), Complete (дальняя пара), Ward (прирост внутрикластерного SSE при объединении).
- **Дендрограмма** — визуализирует иерархию; высота узла = несхожесть его потомков.

## Снижение размерности

Многомерность ведёт к **проклятию размерности** — растёт риск переобучения, данные становятся разреженными.

### Метод главных компонент (PCA)

Проецирует данные на ортогональные векторы, максимизирующие дисперсию. Для матрицы $A$: если $A\vec{x} = \lambda\vec{x}$, то $\vec{x}$ и $\lambda$ — собственный вектор и собственное значение. В PCA собственные векторы некоррелированы и являются главными компонентами.

1. Начинаем с ковариационной матрицы стандартизованных данных.
2. Считаем собственные значения/векторы через SVD или собственное разложение.
3. Ранжируем компоненты по доле объяснённой дисперсии $\frac{\lambda_i}{\sum \lambda}$.

Для $p$-мерных данных будет $p$ главных компонент. PCA объясняет дисперсию в $X$, но не обязательно в $Y$. **Sparse PCA** ограничивает число ненулевых значений в компоненте (устойчивее к шуму, интерпретируемее).

### Линейный дискриминантный анализ (LDA)

Метод с учителем: максимизирует разделение между классами и минимизирует дисперсию внутри классов.

1. Считаем среднее и дисперсию каждой переменной для каждого класса $C_i$.
2. Считаем внутриклассовую $\sigma_w^2$ и межклассовую $\sigma_b^2$ дисперсию.
3. Находим матрицу $W = (\sigma_w^2)^{-1}(\sigma_b^2)$, максимизирующую отношение сигнал/шум Фишера.
4. Ранжируем компоненты по $\lambda$.

Число компонент — не более $C - 1$. Допущения: нормальность переменных, гомоскедастичность, низкая мультиколлинеарность.

### Факторный анализ

Описывает данные линейной комбинацией $k$ латентных факторов: $X = Lf + \varepsilon$ с нагрузками $L$ и скрытыми факторами $f$. **Scree Plot** (график каменистой осыпи) — собственные значения факторов; «локоть», где значения выравниваются, — отсечка числа факторов.

## Обработка естественного языка (NLP)

Преобразует человеческий язык в машинно-читаемый код.

**Техники обработки:**

- **Токенизация** — разбивает текст на слова (токены).
- **Лемматизация** — приводит к базовой форме по словарю (am, are, is → be).
- **Стемминг** — приводит к основе без учёта контекста (ended → end).
- **Стоп-слова** — удаляет частые нерелевантные слова (the, is).

**Марковская цепь** — стохастический процесс без памяти, предсказывает будущее только по текущему состоянию.
**n-грамма** — предсказывает следующий элемент по $n$ предыдущим (на основе цепей Маркова).
**Мешок слов (Bag-of-words)** — представляет текст частотами слов, без контекста и порядка.
**tf-idf** — важность слова для документа в корпусе: частота термина × обратная документная частота (штрафует частые в корпусе слова).
**Косинусная близость:** $\cos(\theta) = \frac{A \cdot B}{\lVert A\rVert \lVert B\rVert}$, диапазон от 0 до 1.

### Векторные представления слов (embeddings)

- **word2vec** — обучается на локальных окнах контекста, размещает похожие слова рядом, кодирует отношения: $king - man + woman \approx queen$. Варианты: **CBOW** (предсказывает слово по контексту) и **skip-gram** (контекст по слову).
- **GloVe** — сочетает глобальную и локальную статистику совместной встречаемости.
- **BERT** — учитывает порядок слов, обучается на сабсловах; в отличие от word2vec/GloVe выдаёт **разные** векторы для разных смыслов слова (cell phone vs. blood cell).

**Анализ тональности:** полярность (позитив/негатив/нейтрал), сдвигатели валентности («really fun», «hardly fun»), эмоции, субъект-объектная классификация.

**Тематическое моделирование:**

- **LDA (латентное размещение Дирихле)** — генерирует $k$ тем, итеративно обновляя назначения слов по параметрам $\alpha$ (смесь тем в документе) и $\beta$ (распределение слов в теме).
- **LSA (латентно-семантический анализ)** — паттерны через tf-idf и снижение до $k$ измерений через SVD.

## Нейронные сети

Пропускает входы через скрытые слои, используя веса и нелинейные функции.

**Перцептрон** — умножает входы на веса, добавляет смещение, подаёт результат $z$ в функцию активации.

**Функции активации:**

| Sigmoid | ReLU | Tanh |
|---|---|---|
| $\frac{1}{1+e^{-z}}$ | $\max(0, z)$ | $\frac{e^z - e^{-z}}{e^z + e^{-z}}$ |

**Softmax** — из выходов финального слоя даёт вероятности классов, сумма = 1: $\frac{e^{z_i}}{\sum e^z}$.

**Функция потерь** — MSE для регрессии, бинарная кросс-энтропия для вероятностной классификации.

**Градиентный спуск** — минимизирует средние потери, двигаясь в сторону наискорейшего спуска с шагом (learning rate) $\gamma$:
1. Инициализируем веса $W$ случайно, близко к нулю.
2. Пока не сойдётся:
   - Считаем средние потери $J(W)$.
   - **Backpropagation** — идём назад от последнего слоя, считаем градиент $\frac{\partial J(W)}{\partial W}$ и обновляем $W \leftarrow W - \gamma\frac{\partial J(W)}{\partial W}$.
3. Возвращаем веса с минимальными потерями.

**Против переобучения:** ранняя остановка по валидации, **Dropout** (случайное отключение узлов), штрафы на веса, **Batch Normalization** (нормализация входов слоя).

**SGD** — использует одну точку для градиента (быстрее, глаже). **Mini-batch** — обучение на малых подмножествах (баланс).

---

## Свёрточные сети (CNN)

Анализируют структурные/визуальные данные, извлекая локальные признаки.

- **Свёрточные слои** — проходят окнами по изображению, применяя веса, смещение и активацию → карты признаков.
- **Пулинг (Pooling)** — понижает размерность и сохраняет пространственную инвариантность (max или average в окне).

Общая архитектура: серия свёрток → ReLU → пулинг для извлечения признаков, затем полносвязный слой для классификации/детекции.

---

## Рекуррентные сети (RNN / LSTM)

Предсказывают последовательные данные через временные связи, учитывая новые входы и предыдущие выходы (скрытые состояния). Сценарии: many-to-one, one-to-many, many-to-many. Используют разделение весов.

Повторное умножение значений > 1 или < 1 ведёт к:

- **Взрыв градиентов** — нестабильность, переполнение.
- **Затухание градиентов** — потеря обучаемости.

Решения: **gradient clipping** (ограничение градиента), **ReLU** (производная не даёт сжатия при $x > 0$), **гейтовые ячейки**.

**LSTM (Long Short-Term Memory)** — учит долгосрочные зависимости через гейты, хранит отдельное состояние ячейки:
1. Забыть нерелевантное из прошлых слоёв.
2. Сохранить релевантное из текущего входа.
3. Обновить состояние ячейки.
4. Выдать скрытое состояние (отфильтрованную версию ячейки).

LSTM можно стекать для улучшения качества.

---

## Бустинг

Последовательно обучает простые модели, исправляющие ошибки предыдущих. В отличие от бэггинга, бустинг обучается на **всех** данных и комбинирует модели через скорость обучения $\alpha$.

- **AdaBoost** — использует взвешивание образцов и «пни» (одноуровневые деревья):
  1. Строим пни по каждому признаку, выбираем лучший по точности.
  2. Даём больше веса ошибочным образцам, где $\alpha = \tfrac{1}{2}\ln\frac{1 - \text{TotalError}}{\text{TotalError}}$.
  3. Повторяем до сходимости.
- **Gradient Boost** — обучает последовательные модели, минимизируя функцию потерь градиентным спуском:
  1. Начинаем с предсказания среднего.
  2. Строим дерево на ошибках (с ограничением глубины/листьев).
  3. Масштабируем деревья на $\alpha$.
  4. Повторяем до сходимости.
- **XGBoost** — быстрый градиентный бустинг с регуляризацией и параллелизацией.

## Рекомендательные системы

Предлагают релевантные объекты, предсказывая оценки. Два типа:

- **Content Filtering** — рекомендует похожие объекты.
- **Collaborative Filtering** — рекомендует то, что нравится похожим пользователям (чаще используется):
  - **Memory-based** — находит соседей по данным оценок (корреляция или косинусная близость):
    - **User-User** — «похожим пользователям тоже понравилось…»; разнообразнее, но страдает от разреженности.
    - **Item-Item** — «те, кому понравился этот объект, любили…»; эффективно, когда пользователей больше, чем объектов; надёжнее.
  - **Model-based** — предсказывает оценки через байесовские сети, SVD, кластеризацию; лучше с разреженными данными.
    - **Матричная факторизация** — раскладывает матрицу «пользователь-объект» на две низкоранговые матрицы с $k$ латентными факторами.

Системы можно комбинировать через ансамбли.

## Обучение с подкреплением (RL)

Максимизирует будущие награды через пары «состояние-действие»: агент выполняет действия в среде, которая обновляет состояние и даёт награду.

**Многорукий бандит** — игрок с автоматами с неизвестными распределениями выбирает стратегию максимизации награды. Иллюстрирует **компромисс исследование-эксплуатация**.

Типы: **model-free** (проб и ошибок, чаще) и **model-based** (доступ к приближённому распределению состояний/наград).

- **Q-значение** $Q(s, a)$ — ожидаемая дисконтированная суммарная будущая награда за состояние и действие.
- **Политика** $\pi(s) = \arg\max_a Q(s, a)$.

Глубокий RL:

- **Value Learning** — приближает $Q(s, a)$ (дискретные действия). $\epsilon$-greedy: $\epsilon$ — вероятность исследования.
  - **Q-Learning** — итерации значения по таблице состояний/действий.
  - **Deep Q Network** — минимизирует Q-loss (квадрат ошибки между целевым и предсказанным Q).
- **Policy Gradient** — напрямую оптимизирует политику $\pi(s)$ (непрерывные действия).
- **Actor-Critic** — гибрид из двух сетей: актёр $\pi(s, a, \theta)$ управляет поведением, критик $Q(s, a, w)$ оценивает действие.

## Поиск аномалий

Ищет необычные паттерны. Аномалии: **редкие** (миноритарный класс) и **непохожие** (сильно отличаются по признакам).

- **Статистика** — Z-тесты, боксплоты, межквартильный размах, сравнение дисперсий.
- **Плотность** — k-NN, local outlier factor, isolation forest.
  - **Isolation Forest** — деревянная модель, помечающая выбросы по anomaly score:
    1. Случайный признак и порог делят данные надвое.
    2. Разбиваем случайно, пока каждая точка не изолирована.
    3. Считаем anomaly score по числу итераций до изоляции.
    4. Если score > порога — выброс.

    Выбросы легче изолировать → у них короче путь в дереве.
- **Кластеры** — точки вне кластеров могут быть аномалиями.
- **Автоэнкодеры** — сети без учителя, сжимающие данные энкодером и восстанавливающие декодером. Ошибка восстановления служит оценкой аномальности.
- **Скрытая марковская модель (HMM)** — моделирует $n$ скрытых состояний $Q$ через $\lambda = (A, B, \pi)$: $A$ — матрица переходов, $B$ — вероятности эмиссий, $\pi$ — начальное распределение. Аномалии — маловероятные наблюдения.

## Временные ряды

Извлекают характеристики из данных, упорядоченных по времени:

- **Стационарность** — среднее, дисперсия, автокорреляция постоянны во времени.
- **Тренд** — долгосрочный рост/падение.
- **Сезонность** — вариации на регулярных интервалах < года.
- **Цикличность** — вариации без фиксированной длины (> или < года).
- **Автокорреляция** — линейная схожесть текущих и лаговых значений.

CV должна учитывать время:

- **Sliding Window** — обучать $F_1$, тест $F_2$; затем обучать $F_2$, тест $F_3$.
- **Forward Chain** — обучать $F_1$, тест $F_2$; затем обучать $F_1, F_2$, тест $F_3$.

**Экспоненциальное сглаживание** — экспоненциально убывающие веса, скользящее среднее:
$$s_t = \alpha x_t + (1 - \alpha)s_{t-1}, \quad 0 < \alpha < 1$$

**Двойное экспоненциальное сглаживание** — рекурсивный фильтр для трендов:
$$s_t = \alpha x_t + (1-\alpha)(s_{t-1} + b_{t-1}), \qquad b_t = \beta(s_t - s_{t-1}) + (1-\beta)b_{t-1}$$

**Тройное** — добавляет $\gamma$ для сезонности.

**ARIMA** — три параметра $(p, d, q)$:

- **AR (авторегрессия)** — прошлые $p$ значений влияют на следующее.
- **I (интегрирование)** — значения заменяются разностями (степень $d$: 0 для стационарных, 1 для нет).
- **MA (скользящее среднее)** — число лаговых ошибок прогноза $q$.

**SARIMA** — добавляет сезонные $P, D, Q$ и длину сезона $s$.

**Prophet** — аддитивная модель с нелинейными трендами и множественной сезонностью: $y(t) = g(t) + s(t) + h(t) + \varepsilon(t)$ (рост, сезонность, праздники, ошибка). Устойчива к пропускам и выбросам.

**GAM (обобщённая аддитивная модель)** — $y = \beta_0 + f_1(x_1) + \dots + f_m(x_m)$, где функции могут быть нелинейными; даёт регуляризованные и интерпретируемые решения.

## Наивный Байес

Классифицирует по метке с наибольшей условной вероятностью. «Наивный», так как предполагает независимость переменных.

$$\text{Теорема Байеса:} \quad P(c_i \mid a) = \frac{P(a \mid c_i)\,P(c_i)}{P(a)}$$

**Gaussian Naive Bayes** — условную вероятность для непрерывных данных считает, предполагая нормальное распределение.

## Статистика

- **p-value** — вероятность, что эффект случаен. Если < уровня значимости $\alpha$ (или тест-статистика > критического значения) — отвергаем нулевую гипотезу.
- **Ошибка I рода (ложноположительная, $\alpha$)** — отвергли верную нулевую.
- **Ошибка II рода (ложноотрицательная, $\beta$)** — не отвергли ложную нулевую.
  Уменьшение ошибки I рода увеличивает ошибку II рода.
- **Уровень доверия $(1 - \alpha)$** — вероятность найти неслучайный эффект, избежав ошибки I рода.
- **Мощность $(1 - \beta)$** — вероятность уловить присутствующий эффект, избежав ошибки II рода.
- **Доверительный интервал** — интервал, моделирующий долгосрочную частоту захвата истинного параметра.

**z-тест** — различие нормально распределённых средних (большое $n$, известные дисперсии). z-оценка: $\frac{x - \mu}{\sigma}$.
**t-тест** — при неизвестных дисперсиях, сходится к z-тесту при большом $n$. t-оценка: $\frac{x - \mu}{s/\sqrt{n}}$.

**Степени свободы** — число независимых измерений до определения оценки параметра.

**Хи-квадрат тесты** — различия между категориальными переменными: $\chi^2 = \sum\frac{(\text{набл.} - \text{ожид.})^2}{\text{ожид.}}$
(согласие / независимость / однородность).

**ANOVA** — сравнение 3+ выборок. **F-оценка** = $\frac{\text{межгрупповая дисперсия}}{\text{внутригрупповая дисперсия}}$.

**Условная вероятность:** $P(A \mid B) = \frac{P(A \cap B)}{P(B)}$. Если $A, B$ независимы: $P(A \cap B) = P(A)P(B)$.
**Объединение:** $P(A \cup B) = P(A) + P(B) - P(A \cap B)$.
**Взаимоисключающие** — не могут произойти одновременно.

**Матожидание** $E[X] = \sum x_i p_i$:
- $E[X + Y] = E[X] + E[Y]$
- $E[XY] = E[X]E[Y]$ если $X, Y$ независимы.

**Дисперсия** $\text{Var}(X) = E[X^2] - E[X]^2$:
- $\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y) \pm 2\text{Cov}(X, Y)$
- $\text{Var}(aX \pm b) = a^2\text{Var}(X)$

**Ковариация:** $\frac{\sum(x_i - \bar{x})(y_i - \bar{y})}{n - 1}$.
**Корреляция:** $r = \frac{\text{Cov}(x, y)}{\sigma_x \sigma_y}$. Независимые переменные некоррелированы (обратное неверно).

## A/B-тестирование

Исследует пользовательский опыт через рандомизированные тесты двух вариантов:

1. Определить метрику и цели эксперимента.
2. Выбрать уровень значимости $\alpha$ и мощность $1 - \beta$.
3. Рассчитать нужный размер выборки на вариант.
4. Случайно распределить пользователей на контроль и тест.
5. Измерить и проанализировать подходящим тестом.

Размер выборки зависит от $\alpha$, $\beta$ и MDE.

- **MDE (минимально детектируемый эффект)** — целевой минимальный прирост над базой.
- **OEC (общий критерий оценки)** — количественная мера цели теста (когда кратко- и долгосрочные метрики обратны).
- **Многовариантное тестирование** — 3+ вариантов, нужны бóльшие выборки.
- **Поправка Бонферрони** — при $n$ тестах каждый на уровне $\frac{\alpha}{n}$ (снижает ложные срабатывания).
- **Сетевые эффекты** — перетекание влияния между группами. Для контроля рандомизируют по времени, кластеру или локации.
- **Последовательное тестирование** — ранняя остановка по границам ошибки I рода; борется с «подглядыванием» (peeking).
- **Когортный анализ** — группы по поведению/времени; выявляет эффекты новизны/первичности.

## Разное

- **Значения Шепли (Shapley)** — маржинальный вклад каждой переменной; сумма всех значений = (предсказание − среднее предсказание). **SHAP** — интерпретируемый метод на основе Шепли.
- **Перестановки** (порядок важен): $\frac{n!}{(n-k)!} = {}_nP_k$.
- **Сочетания** (порядок не важен): $\frac{n!}{k!(n-k)!} = {}_nC_k = \binom{n}{k}$.
- **Левый скос:** Среднее < Медиана ≤ Мода.
- **Правый скос:** Среднее > Медиана ≥ Мода.
- **Вероятность vs правдоподобие** — при ситуации $\theta$ и исходах $O$ вероятность = $P(O \mid \theta)$. Когда $\theta$ неизвестна, $O$ используют для оценки $\theta$, максимизирующей правдоподобие: $L(\theta \mid O) = P(O \mid \theta)$.
