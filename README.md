# My Daily Path

Личный AI-ассистент для жизни, обучения и карьеры. Одно приложение объединяет
умное расписание, отслеживание прогресса, готовку по продуктам из холодильника
и карьерный агент (CV, вакансии, LinkedIn).

Построено на **Next.js 15 (App Router) + TypeScript + Tailwind CSS + Zustand + Dexie (IndexedDB)**.

## Быстрый старт

```bash
npm install
cp .env.local.example .env.local   # заполните ключи AI-провайдера (по желанию для шага 1)
npm run dev
```

Откройте http://localhost:3000 — произойдёт редирект на вкладку «Расписание».

> Windows PowerShell: вместо `cp` используйте `Copy-Item .env.local.example .env.local`.

## Что уже готово (Шаг 1)

- Адаптивный **layout с боковой панелью**:
  - на десктопе sidebar всегда виден, можно свернуть до иконок;
  - на мобильных — выезжающий drawer (кнопка-гамбургер **и свайп от левого края**).
- **Тёмная / светлая / системная** тема (next-themes) с плавным переключением.
- Четыре вкладки-раздела: **Расписание, Прогресс, Готовка, Работа / Карьера**.
- **Единый «живой промт»** — панель ввода внизу (подключение к AI на шаге 2).
- Каркас данных: доменные типы (`src/types`), БД на Dexie (`src/lib/db`), UI-стор (Zustand).

## Что уже готово (Шаг 2 — AI-планировщик)

- **Provider-агностик AI-слой** (`src/lib/ai/provider.ts`) — единый интерфейс над
  OpenAI, Anthropic (Claude) и Grok (xAI). Ключи только на сервере.
- **Централизованная система промтов** (`src/lib/ai/prompts.ts`) с учётом памяти,
  привычек, приоритетов, энергии, еды и отдыха.
- **Zod-валидация** структурированных ответов (`src/lib/ai/schemas.ts`).
- Эндпоинт **`POST /api/ai/plan`** — генерация и перестройка расписания.
- **Оффлайн-фолбэк**: без API-ключа приложение всё равно строит черновой план,
  чтобы можно было протестировать весь поток.
- UI: большое поле естественного ввода + двухдневная агенда с ручным
  редактированием (время/название), статусами и удалением.
- Рабочий **«живой промт»** на вкладке «Расписание» («перенеси английский на вечер»).
- Сторы: долгосрочная **память** (цели/темп/предпочтения) и **расписание** (события + привычки),
  сохраняются в localStorage.

### Как включить настоящий AI

В `.env.local` задайте `AI_PROVIDER` и соответствующий ключ, например:

```env
AI_PROVIDER=openai
OPENAI_API_KEY=sk-...
```

Без ключа планировщик работает в оффлайн-режиме (черновой план).

## Что уже готово (Шаг 3 — все 4 вкладки)

- **Расписание**: календарь FullCalendar (день/неделя/месяц/список) с drag & drop и
  редактированием событий, переключатель Агенда/Календарь, менеджер постоянных привычек.
- **Прогресс**: долгосрочная цель с прогресс-баром, треки обучения со streak’ами
  (часы автоматически считаются из выполненных учебных событий), сводка откликов,
  ежедневный AI-отчёт (усилить/уменьшить), ввод темпа обучения в память.
- **Готовка**: холодильник (ручной + AI-разбор «добавь 5 яиц, молоко и курицу»),
  подбор 3–5 рецептов из имеющихся продуктов, избранное и история.
- **Работа / Карьера**: менеджер версий CV (Markdown-редактор + предпросмотр,
  экспорт `.md` и печать в PDF), AI-поиск и ранжирование вакансий, «Подготовить заявку»
  (адаптация CV + сопроводительное письмо), список заявок со статусами,
  раздел LinkedIn (подключение через OAuth-скелет, идеи постов, напоминания).
- **Единый «живой промт»** работает во всех вкладках и адаптирует данные по контексту.

### AI-эндпоинты

`/api/ai/plan`, `/api/ai/progress`, `/api/ai/parse-items`, `/api/ai/recipes`,
`/api/ai/jobs`, `/api/ai/application`, `/api/ai/post`, `/api/auth/linkedin`.
Все — с оффлайн-фолбэком (работают без ключа) и Zod-валидацией.

## Дорожная карта (дальше)

## Auto-deploy (Vercel)

Production: https://my-daily-path-ebon.vercel.app

- **Cursor agent** — правило `.cursor/rules/auto-deploy-vercel.mdc`: после изменений кода агент деплоит сам.
- **GitHub** — `.github/workflows/deploy.yml`: каждый `push` в `main` → test + lint + deploy.

Один раз для GitHub Actions:

1. [vercel.com/account/tokens](https://vercel.com/account/tokens) → Create Token  
2. GitHub → Settings → Secrets → Actions → `VERCEL_TOKEN`  
3. `git push origin main`
